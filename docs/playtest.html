ソリ押しゲーム「Lodge」プレイテスト

一人が「ホスト」になり、ほかの人はホストに「つなぎ」ます。サーバーは要りません。8 人まで一緒に遊べます。遊ぶ前に、みんな同じ版にそろえてください。

参加のしかた

  1. 1

    ゲームを入れる

    1. Lodge-windows.zip を右クリックして「すべて展開」。
    2. 展開したフォルダの Lodge.exe をダブルクリック。
    3. 青い画面「PC が保護されました」が出たら「詳細情報」→「実行」（署名のない手作りのゲームなので出ます）。
    4. ファイアウォールの画面では「プライベート ネットワーク」にチェックを入れて「許可」。ホストになる人は、ここで許可しないと友達がつなげません。
    1. Apple シリコン（M1 以降）の Mac で動きます。「この Mac について」の「チップ」が「Apple M…」なら大丈夫です。
    2. Lodge-mac.zip をダブルクリックして展開し、Lodge.app を「アプリケーション」へ移す。
    3. Lodge.app を control を押しながらクリック →「開く」→ もう一度「開く」。
    4. それでも開けないときは「システム設定」→「プライバシーとセキュリティ」の下の「このまま開く」。だめならターミナルで:
      xattr -cr /Applications/Lodge.app

  2. 2

    Tailscale でつなぐ準備はじめの 1 回だけ

    1. みんな Tailscale を入れて起動し、Google などのアカウントでログイン（無料）。
    2. ホストになる人は 管理画面 で、自分のパソコンの行の「…」→「Share…」から友達のメールアドレスへ共有。
    3. 友達は届いた招待を開いて「Accept」。
    4. Tailscale のアイコン（Windows は右下、Mac は右上）が「Connected」なら準備できています。

  3. 3

    遊ぶ

    起動すると、雪山に紙の札が 3 枚吊るしてあります。

    左の札
    一人で遊ぶ（仲間は CPU）
    まんなかの札
    ホストになる。下に出る 100. で始まる番号を友達に教えます。右の二枚重ねの紙を押すと番号を写せます
    右の札
    つなぐ。ホストの番号を欄に打ち、赤い「＞」を押します

    ホストが先にまんなかの札を押して待ちます。砂時計が出ているあいだはつないでいるところ。つながると雪山に立ちます。

この版で変わったこと

    困ったとき

    つながらない（家に赤い × が出る）
    • 番号の打ち間違いがないか、ホストの札の番号と見比べる。
    • ホストがまんなかの札を押して、雪山に立っているか。
    • 二人とも Tailscale が「Connected」か。友達はホストの共有を「Accept」したか。
    • ホストが Windows なら、ファイアウォールで Lodge の「プライベート」を許可しているか（「Windows セキュリティ」→「ファイアウォールとネットワーク保護」→「ファイアウォールによるアプリケーションの許可」）。
    • 使うのは UDP の 24680 番。会社や学校のネットでは通らないことがあります。
    • みんな同じ版か（上の日付とコミットを見比べる）。
    途中で切れた
    • ホストがゲームを閉じると、みんなスタート画面に戻ります。ホストがもう一度まんなかの札を押し、みんなつなぎ直してください。
    かくかくする・重い
    • Esc の設定の「3D の描画の解像度（軽さ）」を下げると軽くなります。
    • 設定の「確かめ用の数字（fps・通信）」を入れると、左上に通信の往復の時間（ms）が出ます。100 ms を大きく超えるなら、Wi-Fi から有線にすると良くなることがあります。
    Windows で、HUD は出るのに景色が真っ暗
    • 起動して数秒で、ゲームが自分で描き方を替えて起動し直します（一度ウィンドウが閉じて、また開きます）。
    • それでも真っ暗なら %APPDATA%\Godot\app_userdata\Lodge\logs\godot.log を送ってください。
    ほかの人の画面と違う
    • 斜面の雪のボタンは、それぞれの画面で切れます（財布に入るのはホストが決めた分だけ）。
    • 同時に同じ席へ座ると、二人が同じ席に座れてしまうことがあります。

    気づいたことは、スクリーンショットと一緒に教えてください。くわしい手引きは playtest-online.md。

      作る人向け: 新しい版を配る

      書きかけが混ざらないよう、まっさらな作業場で書き出してから、Releases に載せます。載せるとこのページに出ます（zip を一人ずつ渡さなくてよい）。

      git worktree add ../Lodge-release origin/main
      cd ../Lodge-release && ./build_release.sh && ./publish_playtest.sh

      publish_playtest.sh は build/ のいちばん新しい zip を playtest-<日付>-<コミット> の版として載せ、前の版からのコミットを「変わったこと」に書きます。前に作った zip なら ./publish_playtest.sh build/2026-11-13-42403e1 のように場所を渡します。
