# Lodge をオンラインで一緒に遊ぶ（テストプレイの手引き）

友達どうしで、ネット越しに同じ雪山で遊ぶための手順です。一人が「ホスト」になり、ほかの人はホストに「つなぎ」ます。サーバーは要りません。8 人まで一緒に遊べます。

## 1. ゲームを入れる

### Windows

1. もらった `Lodge-windows.zip` を右クリックして「すべて展開」します。
2. 展開したフォルダの `Lodge.exe` をダブルクリックします。
3. 青い画面「Windows によって PC が保護されました」が出たら、「詳細情報」を押してから「実行」を押します（署名のない手作りのゲームなので出ます）。
4. ファイアウォールの画面が出たら、「プライベート ネットワーク」にチェックを入れて「許可」を押します。ホストになる人は、ここで許可しないと友達がつなげません。

### Mac

Apple シリコン（M1 以降）の Mac で動きます。2020 年ごろより前の Intel の Mac では動きません（「この Mac について」の「チップ」が「Apple M…」なら大丈夫です）。

1. もらった `Lodge-mac.zip` をダブルクリックして展開し、`Lodge.app` を「アプリケーション」フォルダへ移します。
2. `Lodge.app` を右クリック（control を押しながらクリック）して「開く」を選び、出てきた画面でもう一度「開く」を押します。
3. 「開発元を確認できないため開けません」とだけ出て開けないとき（macOS 15 以降）:
   - 「システム設定」→「プライバシーとセキュリティ」を開き、下のほうにある「Lodge.app は…」の横の「このまま開く」を押します。
   - それでも開けなければ、ターミナルで次を打ってから開きます。

```bash
xattr -cr /Applications/Lodge.app
```

## 2. Tailscale でつなぐ準備をする（はじめの 1 回だけ）

Tailscale を使うと、家のルーターの設定をいじらずに、友達のパソコンどうしをつなげられます。無料です。

1. みんな、[tailscale.com/download](https://tailscale.com/download) から Tailscale を入れて起動し、Google などのアカウントでログインします。
2. **ホストになる人**は、Tailscale の管理画面 [login.tailscale.com/admin/machines](https://login.tailscale.com/admin/machines) を開きます。自分のパソコンの行の右の「…」から「Share…」を選び、友達のメールアドレスあてに共有します。
3. **友達**は、届いた招待のメール（またはリンク）を開いて「Accept」を押します。
4. Tailscale のアイコン（Windows は右下、Mac は右上）を押して、「Connected」になっていれば準備できています。

## 3. 遊ぶ

ゲームを起動すると、雪山に紙の札が 3 枚吊るしてあります。

| 札 | 絵 | 使い方 |
|---|---|---|
| 左 | ソリを押す人と、ついて来る二人 | 一人で遊ぶ（仲間は CPU） |
| まんなか | 戸の開いた家と、歩いて来る友達 | **ホストになる**。下に出ている `100.` で始まる番号を友達に教えます。右の二枚重ねの紙を押すと、番号を写せます（LINE などに貼れます）。仲間（CPU）も一人で遊ぶときと同じ 5 人います |
| 右 | 友達の家へ歩いて行く人 | **つなぐ**。ホストから聞いた番号を欄に打ち、赤い「＞」を押します |

- ホストが先に、まんなかの札を押して待ちます。
- つなぐ人は、右の札の行くボタンの所に砂時計が出ているあいだ、つないでいるところです。つながると雪山に立ちます。
- つながらないと、家に赤い × が出ます。「4. 困ったとき」を見てください。
- 遊んでいるあいだに Esc を押すと、設定の画面の下にホストの番号と、来ている人の数が出ます。「スタート画面へ」でやめられます。
- 仲間（CPU）は 5 人（1 人目はゆき）。それぞれ山を選んで登り、米袋で滑り降りて、別の山へ移ります。動かしているのはホストのゲームです。だれが抜けても残り、ホストがやめるといなくなります。来ている人の数には入りません。
- 仲間どうしでも、近くの仲間と雪合戦の対決をしたり、ソリを一緒に押して運んで乗ったりします。ボタンがたまると、自分のソリを買って縫います（2 人まで）。ロッジのソリは、人が 40 m 以内にいなくて誰も触っていないときだけ、丘の中で使います。
- 雪玉を持って、見ている仲間に低い手のひらを差し出すと、40 m 先からでも来て雪合戦の対決ができます。ソリを押していると、30 m 以内の仲間が手伝いに来て、一緒に乗ります。

### おもな操作

| キー | すること |
|---|---|
| W A S D | 歩く・ソリをつかんでいるときは押す |
| Shift | 走る |
| Space | 跳ぶ |
| F | ソリの縁をつかむ・紐を持つ・手を離す |
| E | ソリに乗る・降りる |
| マウス | 見回す |
| C | 自分の姿が見える視点（三人称）に切り替える |
| Tab | 身ぶりの輪（手を掲げる・声） |
| 1〜7 | 身ぶりと声（ハイタッチは、向かい合って高い手のひら） |
| 左クリック | 雪玉を投げる（押しているあいだ振りかぶる） |
| Esc | 設定 |

画面のアイコンも、近づくと使えるキーを教えてくれます。

## 4. 困ったとき

**つながらない（家に × が出る）**
- 番号の打ち間違いがないか、ホストの札の番号と見比べてください。
- ホストがゲームでまんなかの札を押して、雪山に立っているか確かめてください。
- 二人とも Tailscale が「Connected」になっているか確かめてください。友達はホストの共有を「Accept」したか確かめてください。
- ホストが Windows なら、ファイアウォールで Lodge を許可しているか確かめてください（「Windows セキュリティ」→「ファイアウォールとネットワーク保護」→「ファイアウォールによるアプリケーションの許可」で Lodge の「プライベート」にチェック）。
- 使っているのは UDP の 24680 番です。会社や学校のネットでは通らないことがあります。

**途中で切れた**
- ホストがゲームを閉じると、みんなスタート画面に戻ります。ホストがもう一度ホストの札を押し、みんなつなぎ直してください。

**動きがかくかくする・重い**
- はじめて起動したときに、ゲームがパソコンの速さを測り、画質（軽さ）を合わせます（最初の 10〜20 秒ほど）。
- それでも重いときは、Esc の設定の「画質（軽さ）」をいちばん軽い「ガビガビ」にしてください。景色が荒い粒になるかわりに、内蔵の GPU でも動きやすくなります。
- Esc の設定で「3D の描画の解像度（軽さ）」を下げても軽くなります。

**Windows で、HUD は出るのに景色が真っ暗**
- 起動して数秒で、ゲームが自分で描き方を替えて起動し直します（Vulkan → Direct3D 12 → OpenGL の順）。一度ウィンドウが閉じて、また開きます。
- それでも真っ暗なら、`%APPDATA%\Godot\app_userdata\Lodge\logs\godot.log` を送ってください。
- 設定の「確かめ用の数字（fps・通信）」を入れると、左上に通信の往復の時間（ms）が出ます。100 ms を大きく超えるときは、Wi-Fi から有線にすると良くなることがあります。

**ほかの人の画面と違うことがある（テスト中なので）**
- 斜面の雪のボタンは、それぞれの画面で切れます（お財布に入るのはホストが決めた分だけ）。
- ロッジの席は、同時に同じ席へ座ると、二人が同じ席に座れてしまうことがあります。
- 気づいたことは、スクリーンショットと一緒に教えてください。

## 作る人向け: 書き出しと配り方

Godot 4.6.3 と、その書き出し用の雛形（エディタの「エクスポートテンプレートを管理」、または公式の `Godot_v4.6.3-stable_export_templates.tpz`）が要ります。書きかけが混ざらないよう、まっさらな作業場で動かします。

```bash
git worktree add ../Lodge-release origin/main
cd ../Lodge-release && ./build_release.sh
```

`build_release.sh` は次をまとめてします。できた zip は `build/<日付>-<コミット>/` に置きます。

- 音（`sound/wav`）をゲームの中に入れる。音はふだんゲームの外から読むので、入れないと書き出したゲームは鳴りません。
- Windows は `Lodge.exe` ひとつにまとめ（中身を exe に埋め込む）、フォルダごと `Lodge-windows.zip` にする。
- Mac は Apple シリコン専用にする。Godot の雛形は Intel と Apple の両方入りしかないので、書き出したあとに Intel の分を抜いて、署名し直す（両方入りのままだと、本体が約 2 倍、zip が約 90 MB 大きくなります。Intel の Mac に配るときは、スクリプトの 5 の `lipo` を飛ばします）。Apple の公証はしていません（その場しのぎの署名だけ）。

- `build/` は git に入れません。zip は Google ドライブなどで渡します。itch.io の限定公開（リンクを知っている人だけ）でも配れます。
- 書き出しの設定は `game/export_presets.cfg`。`tools/` と `shots/` は入れません。
