# 滑りあとの縫い目の見本帳

ソリの滑り木が雪（毛糸の編み地）に残す跡を、縫い目の柄で描く。ソリを縫ったミシンの縫い目が、そのまま雪に残るという設定。

2026-10-27 の代表の決め:

- **標準の跡は、重いソリほど太くて丈夫な縫い目。** 豪華さではなく、強さで重さを表す
- **凝った柄は、報酬かゲーム内の通貨で手に入れる差し替え。** カスタマイズの幅になるものは、いくらあってもいい。柄をたくさん調べてためておく
- 糸の色はソリのフェルトに合わせるのが標準。色の差し替えも、柄とは別のカスタマイズにできる

![見本帳](renders/07-stitches-swatch.png)

左から `running` `chain` `zigzag` `triple_zigzag` `saddle` `herringbone` `feather` `garden`。描き方は `build_sled.py -- --swatch all`。

## 作ったもの

| 名前 | 縫い目 | 見え方 | 使いどころ |
|---|---|---|---|
| `running` | なみ縫い | 軽い破線 | 標準: 1 人乗り |
| `chain` | くさり縫い | しずく形の輪がつながる | 標準: 3 人乗り |
| `saddle` | サドルステッチ | 蝋を引いた太い糸の斜めの目が 2 列。革を縫う、いちばん丈夫な手縫い | 標準: 6 人乗り（2026-10-27 代表が選んだ） |
| `herringbone` | 千鳥がけ | 太い糸の × が連なる。裾を留める丈夫な縫い目 | 差し替え（丈夫な系） |
| `triple_zigzag` | 三重ジグザグ | 同じジグザグを 3 回重ねた太い帯。伸びに強いミシンの縫い目 | 差し替え（丈夫な系） |
| `zigzag` | ジグザグ | 細いジグザグ | 差し替え |
| `feather` | フェザーステッチ | 左右に枝分かれする羽根 | 差し替え |
| `garden` | 花の蔓 | 波打つ茎（ステムステッチ）に 5 枚の花びらの花（レゼーデージー）と葉、花の芯はフレンチノット。赤・緑・山吹の 3 色 | 報酬・買い物 |

## ゲームの中の跡（Godot。2026-10-29）

| 名前 | 縫い目 | 見え方 | 使いどころ |
|---|---|---|---|
| 滑りあと | 太い 2 本撚りのジグザグ | 雪より濃い毛糸の青。左右の滑り木の 2 本 | ソリが滑った跡（`look.gd` の `stitch_mesh`） |
| 引きずられ跡 | ぐし縫いのギャザー | 赤茶の毛糸の短いなみ縫いが、かかとの 2 本の線に並ぶ。目のまわりの雪の編み地が縫い縮められ、ひだが寄る。速く引きずられるほどひだが濃い | 速いソリをつかんで引きずられた人のかかとの跡（`look.gd` の `gather_stitch_mesh`）。絵は `design/sled-drag/heel-stitches.png` |

## これから作る候補（調べてためる）

丈夫さ（太い・詰んだ・重ねた）と、飾り（花・模様・色数）の 2 つの軸で並べる。丈夫なものは重いソリの標準や上位の差し替えに、飾りのものは報酬に向く。

### 丈夫な縫い目（重いソリ向き）

| 縫い目 | 見え方 |
|---|---|
| 三重直線縫い | 同じ線を 3 回往復した太い直線。ミシンのいちばん丈夫な直線 |
| 太糸のバックステッチ | 隙間のない太い実線 |
| コーチング | 太い毛糸を置き、細い糸で一定間隔に留める。2 色 |
| ブランケットステッチ（太糸） | 櫛の歯が片側に並ぶ。ソリの座布団の縁と同じ縫い方 |
| ダブル千鳥がけ | 千鳥がけを 2 色で重ねる。網目が詰む |
| 刺し子の一目刺し・米刺し | 雪国の、布を丈夫にするための刺し子。点と十字が並ぶ |
| オーバーロック | 布端を巻く密な糸の帯 |

### 飾りの縫い目（報酬向き）

| 縫い目 | 見え方 |
|---|---|
| 刺し子の柄（麻の葉・七宝つなぎ・青海波・柿の花・十字花刺し） | 幾何学の連続模様。日本のゲレンデの個性と合う |
| クロスステッチの雪の結晶 | × で描いた結晶が一定間隔に並ぶ |
| ウィップドランニング・スレッデッドランニング | なみ縫いに別の色の糸を巻く・くぐらせる。2 色の波 |
| クレタンステッチ・フィッシュボーン | 葉脈のような帯 |
| フライステッチ | Y の字が並ぶ。小鳥の足あと |
| ブリオンステッチの小花 | 糸を巻いた粒で作るつぼみ |
| サテンステッチのハート・星 | 面を埋めた小さなモチーフが点々と |
| ペキニーズステッチ | バックステッチに輪を通した、組みひものような帯 |
| ミシンの飾り縫い（スカラップ・葉・ハート） | ミシンに入っている模様縫い |
| リボン刺しゅう | 幅のあるリボンの花 |

### 色のカスタマイズ

- 糸の色: ソリのフェルトと同じ（標準）、生成り、藍、山吹、2 色ねじり
- 毛糸の太さ: 細糸・並太・極太（極太は重いソリの標準と組み合わせない。違いが読めなくなる）

## ゲームに入れるとき

- 跡は、滑り木の通った道に沿って伸ばす細い帯のメッシュに、柄の画像を繰り返して貼るのが軽い
- 柄の画像は、この台本で 1 m 分の柄をまっすぐ描き、真上から正投影で撮って、透過の PNG にする（まだ作っていない）。帯の幅は柄ごと（`running` 約 4 cm、`herringbone` 約 20 cm、`garden` 約 50 cm）
- 3 人乗り以上は滑り木の本数だけ跡が並ぶ。`garden` は 6 人乗りの真ん中の滑り木に花の蔓、左右にフェザーステッチ（`--trail-large garden` で見られる）
