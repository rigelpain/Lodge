# ソリのゲーム（仮題）

ゲレンデで大きなソリをみんなで押して丘を登り、一緒に乗って一気に下る、3D 一人称の協力ゲーム。Steam での販売を目指しています。

- 開発ダッシュボード: `docs/`（GitHub Pages で公開。中身は `docs/data.json` を書き換える）
- 絵柄の見本: これから `prototypes/` に置く
