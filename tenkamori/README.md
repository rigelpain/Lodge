# 天下森のワールド（2026-11-09）

横手市増田町の天下森スキー場を、本物の標高で起こした別のワールド。今までの世界（ロッジと丘と大きな山と大山）はそのまま「プレーンなワールド」として残し、スタート画面で選ぶ。

代表「今まで作ってたのをプレーンなデフォルトワールドとして、別のワールドって感じで作ってほしい」「これはノスタルジーを感じさせる目的でつくるので、ゲレンデから見える景色、つまりコースの逆側の山の作りがかなり重要」

- ゲームの側: `game/tenkamori.gd`（地面・向かいの山・地平線・林）、`game/tenkamori_lift.gd`（第一ペアリフト）、`game/hutte.gd`（夏虫沢ヒュッテ）、`game/main.gd` の `stage`、`game/start.gd` のワールドの札、`game/net.gd` の `_world`（つないだ人をホストのワールドへ移す）
- 焼いた表: `game/tenkamori/`（`bake_terrain.py` が書く。書き方は台本の頭）
- 確かめ: `game/tools/tenkamori_views.gd`（決まった所から撮る・頂上からソリを放す）

## 焼き直し

```bash
python bake_terrain.py <タイルを置くフォルダ> <OSM の JSON のフォルダ>
```

numpy と Pillow が要る。タイルはフォルダに無ければ国土地理院から取る。OSM の JSON（`osm.json` ゲレンデ・リフト、`bld.json` 建物・道）は Overpass API から取った物（取り方は下）。

## 決めたこと

- 座標: 原点 = 第一ペアリフトの乗り場、x = 東、z = 南。高さ = 標高 − 227.3 m。大きさは本物のまま（乗り場から頂上まで 139 m、リフト 787 m）
- 近く（1024 m 四方、2 m おき）だけ当たり判定がある。向かいの山（8 km 四方）と地平線（38 km 四方）は見た目だけ。遠くは地球の丸みで下げる
- 林: 雪の白・雑木の灰・杉の濃い色を、斜面の急さと大きな斑で塗り分け、木立のざらつきはシェーダーの粒で描く（代表が見せた YouTube「天下森スキー場1」と PV の、向かいの山の見え方）。ゲレンデの縁から 40 m まではフェルトの木を 1 本ずつ置いて当たりを付け、その外は MultiMesh（128 m の区画ごと、420 m より遠い区画は描かず、地面に重ねた林の色で見せる）
- 林の木の色（2026-11-09 代表「色は近いものにしましょう」）: とがった 2 つの形（tree_tall・tree_zigzag）だけにし、葉のフェルトに濃い青緑を掛ける（`tenkamori.gd` の `CEDAR_LEAF`）
- 頂上から放したソリが、中ほどのゆるい所（3 分の 1 ほど下）で止まるのは本物の地形どおり。代表「途中で止まるのはいいでしょう」
- リフト: OSM の線の 14 点（乗り場・柱 12 本・降り場）に、乗り場（薄緑の骨組み・横倒しの滑車・床と手すり・黒い機械小屋・木の小屋）と柱を立て、2 人掛けの椅子が索を回る（2 m/s、14 m おき）。乗れるのはまだ
- ヒュッテ: 旧・夏虫沢ヒュッテ（平成7年竣工・木造平屋。2019 年のストリートビューの姿）。代表「旧ヒュッテ（2019）」。図面に起こしてから組んだ（代表「画像そのままで作る前に図面に起こしたほうが良い」）。寸法は `hutte/dims.py`、図面は `design/tenkamori/hutte-old/01-plans.png`、組み方は `game/hutte.gd`。写真と並べた絵は `design/tenkamori/hutte-old/02-compare.jpg`。入口から休憩室まで人がつかえずに入れることを `game/tools/hutte_walk_check.gd` で確かめた
- 屋根（2026-11-09 代表「屋根を棟にぶっ刺した感じなのやめてほしい」「屋根同士の接続部分が汚すぎる」）: ヒュッテの屋根は、重なる屋根の面のうちいちばん高い面をとる一つの面（`hutte.gd` の `_roofs`）。交わる所はそのまま谷になり、裏が天井。壁の上は屋根の裏まで届く
- 道と駐車場（2026-11-09 代表「ロッジ周囲の道路と駐車場も作ってください」）: OSM の道（県道・市道・取り付けの道）と駐車場を、`bake_terrain.py` がならし（道は中心の線の高さを 20 m でならして幅の中を平らに、縁の外に除雪の雪の壁 0.9 m）、`road.bin` に濃さを書く。見た目は踏み固めた雪の灰（`tenkamori.gd` の WOODS_OVER の road_a・road_b）。木は道から 7 m と駐車場の中に立てない
- リフトに乗る（2026-11-09 代表「リフトに乗れるようにしてほしい」）: 乗り場の乗る所で F。次の椅子を待って座り、約 7 分で降り場でひとりでに降りる。そばの自分のソリは椅子の下に吊って上げ、降り場の脇に置く（`tenkamori_lift.gd`・`player.gd` の lift_*）。椅子の位置は時計から決めるので、どの画面でも同じ。確かめは `game/tools/lift_ride_check.gd`
- ゲレンデの作り込み（2026-11-09 代表がくれた動画 2 本 → 見取り図 `design/tenkamori/slope/01-slope-map.png` →「これで作って」）:
  - 林間コース: OSM の線に沿って幅 9 m を横に平らに切り込み、谷の側に雪の壁 1 m（`bake_terrain.py` の carve_rinkan）
  - 木: 国土地理院の空中写真（z17）の暗い緑を林と見て、そのとおりに杉を立てる（`forest.bin`）。林間コースの両脇 3〜25 m は林にする（中ほどは開ける）。全部 MultiMesh、開けた所から 12 m の木だけ幹の当たり
  - 圧雪の筋: ゲレンデと林間コース（`piste.bin`）に、斜面を下る向きの細い畝と 5 m の通り道の境（`tenkamori.gd` の WOODS_OVER）
  - 小物（`tenkamori_slope.gd`）: リフトの柱のマットと赤いネット、ナイターの照明の柱、林間コースの曲がりと合流のオレンジのネット、下の斜面の縁の小屋、降り場の札
  - 動画と並べた絵: `design/tenkamori/slope/02-compare.jpg`。林間コースの上からソリを放すと、道に沿って 150 m ほど下り、曲がりで止まる（曲がるのは乗る人の体重移動）
- まだ無いもの: ヒュッテの中の店や機械（料理・服・ソリ）、山をめぐる仲間（CPU）、雪のボタン。天下森では設定の CPU の数を止めてある

```
[out:json];(way(around:600,39.1623,140.6208)["building"];way(around:600,39.1623,140.6208)["highway"];
way(around:600,39.1623,140.6208)["amenity"="parking"];);out geom;                  → bld.json
```

## 雪面のこぶとうねり（2026-11-12）

代表「天下森もロッジも起伏増やしたいね」: 焼いた地面（near.bin）に、旭ヶ丘と同じこぶとうねり（波長 40・16・8 m）を足す（`tenkamori/add_snow_relief.py`）。焼き直しに要る OSM の JSON が手元に残っていないので、焼き直さずに足した。足す前の地面は `tenkamori/near_base.bin`（何度走らせても足すのは 1 回分）。林・道・駐車場・ヒュッテとリフトの乗り場と降り場の足もとには足さない。ヒュッテの通り抜け（つかえた点 0）とリフトに乗れることを確かめた。絵は `design/asahigaoka/08-relief-plain-tenkamori.jpg`
