# 染めと着替えの人台（2026-11-04）

代表「染め桶と衣装掛けは一つの施設に統合できたら嬉しい。アートコンセプトに則って3案ほしいな」。

## 決まったこと

- 形: 3 案（A 染め場の干し櫓・B 大きな人台・C 大きな裁縫箱）から、代表は「2 が一番好きだけど 1 の長く伸ばされた布が染物屋感を強く感じる」。B に A の長い布を足した 2 通りから E（天井の輪）を選んだ
- 裾: 代表「トルソーのスカート的部分の布の色は白がいいです」。染めても裾と長い布の色は変わらず、桶の液と縁の布だけが染めた色になる
- 腰の輪と裾の始まり: 代表「人形もうちょっと高いほうが良い」「トルソーの腰のクビレの位置に持っていったら今の意味不明なスカート始まり位置も良くなる」。くびれの高さ（床から 3.12 m）に上げた
- 置き場: 1 階の南西の隅（入口の左）。代表「紙細工士さんはこの染台の横に」「染台と紙細工士さんは今のソリ屋が外に行って開いた場所に移動させてください」。南から人台、テントと並び、どちらも正面は東（入口からの通り道）。ソリ屋を外の下屋へ移す作業のあとに入れる

## 作り

- 形: `ideas.py`（Blender）。`--what E --export game/props/dress_form` で `dress_form.glb` を書き出す（桶・人台・腰の輪・天井の輪と梁・長い布・櫂）
- ゲーム: `game/wardrobe.gd`（人台。glb・当たり・ハンガーと人形）と、子の `game/dye_vat.gd`（染め液と縁の布）。置く所は `main.gd` の `WARDROBE_AT`・`PAPER_LADY_AT`
- F: 同じ所で、人形の高さを見て押すと着替え、桶を見下ろして押すと染める（`player.gd` の `looks_down`。約 17° より下）。後ろの長い布の側では人形は選べない
- 確かめ: `game/tools/dress_form_shots.gd`
