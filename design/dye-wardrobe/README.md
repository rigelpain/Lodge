# 染めと着替えの人台（2026-11-04）

代表「染め桶と衣装掛けは一つの施設に統合できたら嬉しい。アートコンセプトに則って3案ほしいな」。

## 決まったこと

- 形: 3 案（A 染め場の干し櫓・B 大きな人台・C 大きな裁縫箱）から、代表は「2 が一番好きだけど 1 の長く伸ばされた布が染物屋感を強く感じる」。B に A の長い布を足した 2 通りから E（天井の輪）を選んだ
- 裾: 代表「トルソーのスカート的部分の布の色は白がいいです」。染めても裾と長い布の色は変わらず、桶の液と縁の布だけが染めた色になる
- 腰の輪と裾の始まり: 代表「人形もうちょっと高いほうが良い」「トルソーの腰のクビレの位置に持っていったら今の意味不明なスカート始まり位置も良くなる」。くびれの高さ（床から 3.12 m）に上げた
- 置き場: 1 階の南西の隅（入口の左）。代表「紙細工士さんはこの染台の横に」「染台と紙細工士さんは今のソリ屋が外に行って開いた場所に移動させてください」。南から人台、テントと並び、どちらも正面は東（入口からの通り道）。ソリ屋を外の下屋へ移す作業のあとに入れる

## 染める部位の指し方（2026-11-04）

代表「他の部位の色を褪せさせるんじゃなくて、染色部位の輪郭を表示して染色部位を少し光で点滅させるのが良いかと」「範囲の内側を微光させる感じで点滅が良いな」。

- ほかの部位はもとの色のまま。画面を開いている間ずっと、選んでいる部位（見本に乗っている間はその部位）に輪郭と微光を出す
- 輪郭: 部位の外側に、生成りの糸の芯と墨の縁の 2 色。濃い布の上は芯で、白い布や生成りの札の上は縁で読める。太さは 1080p で芯 2.6 px・縁 1.5 px（`game/dye_ui.gd` の `RING_CORE`・`RING_EDGE`）
- 細かい所: musha の縅の糸のように狭いすき間で並ぶ所は、1 本ずつでなくひとかたまりで縁取る（すき間を埋める幅は `SHAPE_SHADER` の `R`）
- 微光: 輪郭の内側の範囲だけが点滅する。輪郭のすぐ内側で強く、中へ行くほど薄い（届く幅は `GLOW_R`、まん中の強さは `RING_SHADER` の `GLOW_MID`）。範囲じゅう同じ強さにすると布の色が替わったように見えるので、縁から薄れる形にした
- 光の色: 暗い布には布の色寄りの光を足す（灯りの色だけだと紺が灰色に褪せて見える）。白い布は陰を残したまま灯りの色に少し染める（`RING_SHADER` の `lit`）
- 点滅: 1 周 1.3 秒でなめらかに（`BLINK`。アートコンセプトの「12 コマは人の姿勢だけ」に合わせた）。輪郭は点滅しない。いちばん弱い所で布は本当の色に戻るので、選んだ色も確かめられる
- 作り: 同じ人形をもう 1 体、部位だけ白く塗って同じカメラで撮り（`game/outfit.gd` の `part_material`）、見本の絵に 2D で重ねる。前にある物の陰になる所は輪郭も出ず、人形が回ると出てくる。ゲームの中の人形の材質には何も足していない
- 確かめ: `game/tools/dye_shots.gd --grid`（7 体 × 4 部位の札を、もとの色と染めた色、表と裏で撮る）

## 作り

- 形: `ideas.py`（Blender）。`--what E --export game/props/dress_form` で `dress_form.glb` を書き出す（桶・人台・腰の輪・天井の輪と梁・長い布・櫂）
- ゲーム: `game/wardrobe.gd`（人台。glb・当たり・ハンガーと人形）と、子の `game/dye_vat.gd`（染め液と縁の布）。置く所は `main.gd` の `WARDROBE_AT`・`PAPER_LADY_AT`
- F: 同じ所で、人形の高さを見て押すと着替え、桶を見下ろして押すと染める（`player.gd` の `looks_down`。約 17° より下）。後ろの長い布の側では人形は選べない
- 確かめ: `game/tools/dress_form_shots.gd`
