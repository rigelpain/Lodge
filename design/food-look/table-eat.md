# 机のある席での食べ方（2026-11-06）

代表「座って食べるときだけ、麺類はすするモードにして3口で食べるんじゃなくてちゃんと端ですすってたべたり、肉まんとかはりょうてでもってはふはふしたり、焼き魚は箸でほぐしながら食べたりするようにして欲しい。それぞれの食べ物に対してあった食べ方のモードに、机のある椅子に座って食べるときだけ変化するようにして欲しい」

- 作りは `game/table_eat.gd`。品と食べ方の対応は `STYLE_OF`、食べ方ごとの長さと音は `STYLES`、動きは `pose()`
- 絵: [03_table_eat.jpg](03_table_eat.jpg)（9 つの食べ方。一人称と人形）、[04_table_eat_net.jpg](04_table_eat_net.jpg)（つないだ相手の画面）

## どの席で変わるか

席に `table`（皿を置く所）があれば、この食べ方になる（`game/seats.gd` の `_mark_table`）。席の前を探って当たった物の上に、腰の面より 5〜90 cm 高い平らな面があるときだけ、机とする。

| 席 | 数 | 机 | 食べ方 |
|---|---|---|---|
| 食堂の椅子（chair） | 60 | あり | 変わる |
| 窓辺のカウンターの丸椅子（stool） | 37 | あり | 変わる |
| 2 階の掘りごたつの座布団（zabuton） | 64 | あり（天板） | 変わる |
| 暖炉のまわりのソファ（sofa） | 8 | なし | 3 口のまま |
| 揺り椅子（rocker） | 3 | なし | 3 口のまま |
| ビーズクッション（beanbag） | 4 | なし | 3 口のまま |
| 立っているとき | | | 3 口のまま |

こたつは「変わる」にした。天板に皿を置いて向かい合って食べる席で、椅子の席と同じ姿勢で手が届くから。掘りごたつの座布団では目が天板より下になっていたので、机のある席では目を机の面より 42 cm 以上上にした。

## 品ごとの食べ方

| 食べ方 | 品 | 動き |
|---|---|---|
| すする slurp | ラーメン・うどん・そば・焼きそば | 器は机の上。箸で麺を高く持ち上げ、押しているあいだ切れ目なくすする。3 口に分けず、麺が 1 本ずつ器の側から短くなって減る |
| はふはふ hafu | 肉まん・たい焼き・コロッケ・ハッシュドポテト・ホットサンド・焼き芋 | 両手で持ち上げ、口の前で白い息を 3 回はふはふ、かじって噛む |
| かぶりつく gabu | おにぎり | 両手で持ってかぶりつく（冷めても食べる物なので、はふはふはしない） |
| ほぐす flake | 焼きサンマ・焼き牡蠣 | 器は机の上。箸で身を 3 か所つついてほぐし、かけらを口へ |
| 切る cut | ホットケーキ | 右手のナイフで切り、左手のフォークで口へ |
| つまむ pinch | ポテト | 箱は机の上。手で 1 本つまんで口へ |
| さじ spoon | クラムチャウダー | 器は机の上。木のさじですくって口へ |
| 両手で飲む cup | ココア・コーンポタージュ・緑茶・ホットミルク・ミルクティー | 両手で包んで持ち上げ、ふーっと吹いて、傾けてすする |
| 椀と箸 wan | お汁粉 | 左手で椀を持ち上げ、右手の箸で餅を口へ |

調べた所: 器を両手で持って安定させてから箸を取る順（[和食の器の持ち方の解説](https://precious.jp/articles/-/9463)）、焼いたお餅は手でも箸でもよい（[お餅の食べ方のマナー](https://precious.jp/articles/-/16408?page=27)）。たい焼き・焼き魚・はふはふについては決まった作法の記事が見つからなかったので、ふだんの食べ方から決めた。

## 作り

- **出来事**: `{kind: "eat_t", who, dish, style, len, bites, first, last, frame}`（`emotes.gd`）。数と文字だけなので、ホストが配って全員の人形が同じコマで動く
- **机の状況**: `doll.eat_table`（皿の所・品・食べた口数）。持ち主が毎フレーム入れ、通信では姿の `te` に載る
- **姿勢**: `TableEat.pose()` は点の組を受け取って手と道具の先を返す。一人称は目の高さの水平な基準（カメラの空間にすると、見下ろしたとき手が机に潜る）、人形は骨の空間。動きはコマだけで決まる（12 コマ／秒）
- **描く役**: `TableEat.Rig`。机の皿・手の道具・すする麺を描く。一人称の手の層と人形の層に 1 つずつ
- **麺**: `<名前>_nn0〜2.glb` は麺だけ抜いた器。麺はゲームが管の形で作る。残りの本数は `slurp_done`（食べた口数＋いまのコマ）で決まる
- **箸・さじ・フォーク・ナイフ**: `make_tool`。ゲームの木の素材（`Look.wood`）で作る
- **音**: `eat_hafu`・`eat_blow`・`eat_cho` を `sound/gen/eat.py` に足した（合成）
