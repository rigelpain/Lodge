# 大きな山を自然な形に（2026-11-03）

代表「大きい山のほうが変に凹ませてあってコースっぽく見えるのが嫌だ。あと大きな段差があるが、押して登る前提なのだからそんな横長に段差作ったら迂回が大変でしょう。ジャンプ台になる段差は幅小さく作ってほしい。あとジャンプちゃんとできるように射出する角度を作ってほしい。」
代表「ゲレンデの木が浮いてるのが気になる」
