標準は素朴で丈夫に、凝ったものほど高くした。2 階の売り台の小物とミニオンの値段の段（40〜1500）に合わせている。

## 作り

- 形: `props/build_lantern.py`（`--sheet` で案の絵、`--look flat --export game/props/lantern` で glb）。光る所はどれも役割 `paper` で書き出し、
  色は Godot の `game/lantern.gd` の `LOOK` で染める
- 揺らぎ: `lantern.gd` の `flicker(style, t, seed)`。帯のランタン・ランタン掛け・売り台の札で同じものを使う
- （2026-11-02 に、売り場は 2 階の紙細工屋さん `game/paper_lady.gd`・`game/paper_shop_ui.gd` の提灯の段へ移した。下の 2 行は前の作り）
- ランタン掛け: `game/lantern_rack.gd`（2 本の柱に竿を上下 2 本、5 つずつ灯して提げる。下に赤いフェルトの台と木の料金箱）。
  置き場は `main.gd` の `LANTERN_RACK_AT`（番台の座標）
- 買う画面: `game/lantern_ui.gd`（前で F。札を押すと、持っていれば提げ替え、持っていなければ買ってすぐ提げる。提げている札をもう一度押すと外す）
- 出来事: `craft.gd` の `lantern_buy {look}`・`lantern_own {look}`・`equip {gear: "lantern", index}`。
  通信を入れたら、ほかの人の画面でも、その人の帯のランタンが替わる（人形は `craft.lantern(who)` を毎フレーム読む）
- 保存: `player.gd` の `save_tag` の `[lantern]`（持っている形と、提げている形）
- 装備の画面（I）: ランタンの札は数に合わせて列を増やして小さくする（10 枚で 5 列 2 段）。絵は `craft_icons.gd` の `lantern`
- 保存は、この画面から送った出来事が返ってきたときに書く（つなぐ側は、ホストが確かめて配り返してから）
- ランタンは装備（帯に提げる物）で、手持ち 6 ＋ かばん 6 の持ち物の場所は使わない。装備の画面（I）の左下の札に並ぶ
- 確かめ: `game/tools/lantern_variety_shots.gd --part=line|rack|ui|load|net|bots`
- 書き出し: GPU（Metal）の焼き付けが螺鈿で止まったまま戻らなかったので、`KIT_CPU=1` を付けて CPU で焼いた（`props/kit.py`）
