# Lodge 音の設計

2026-10-27。[アートコンセプト](art-concept.md)の「音」の節から起こした。音は合成を土台にし、録音は条件つきで使う（下の「素材の決まり」）。生成の台本は `sound/gen/`、音は `sound/wav/`、Godot 側は `game/audio.gd`。

## 一言で

**雪が吸った、乾いた音。** 壁がないので響かない。雪が高い音を吸う。遠くの音は細く、近くの音は乾いて粒が立つ。手芸の世界の音は、やわらかく、こもらず、乾いている。

## 決まり

1. **場にあるものしか鳴らない。** 音楽はゲレンデの柱のスピーカーから届く。画面の外から鳴る BGM、決定音、達成の音はない
2. **外は響かない。** 屋外の残響はゼロ。奥行きは残響ではなく、距離で高い音が落ちることと、同じ曲が柱ごとにずれて届くことで出す。響くのはロッジの中だけ
3. **言葉はない。** 掛け声、アナウンスはない。声は言葉にならない 3 つだけ（「ワ〜」うれしい、「ウン」うなずき、「ンーン」いやいや。2026-10-28、代表の声で足した）と息

## 鳴るもの・鳴らないもの

| 鳴る | 鳴らない |
|---|---|
| 雪を踏む足あと（自分と、まわりの人のぶん） | 言葉、アナウンス |
| 押している人の息 | BGM（場に音源のない音楽） |
| ソリの滑り木が雪をこする音 | 決定音・達成音・ジングルなど画面の音 |
| 風（高さと速さで変わる） | 鳥、動物、虫 |
| 柱のスピーカーから届く曲 | 屋外の残響 |
| ロッジの中: 薪、炉の火、鍋、食器、板の床の足音、戸 | ぶつかる音。フェルトと紙はぶつかっても鳴らない。木の縁をつかむ小さな音だけ |
| 言葉にならない声（ワ〜・ウン・ンーン）、身ぶりの小さな音（手袋が合う・雪玉が崩れる） | |

## 素材と音

| 素材 | 音 |
|---|---|
| 毛糸の雪 | 片栗粉を握ったときの「ギュッ」。冷えた粉雪の鳴き。ざらざらした粒の音や、濡れた雪の重い音にはしない |
| 木（滑り木、ソリの台、ロッジの床） | 乾いた木。こすれ、きしみ、かたい足音 |
| フェルト（上着、木、屋根） | ほぼ鳴らない。音を吸う側 |
| 紙（人の体） | 軽い。足あとは体重の軽い音。息はふつうの人と同じ |

## 素材の決まり

2026-10-27 に代表が「無料で DL できるものなら外の素材を使ってよい」と緩めた。心配はライセンス。だから条件を先に決める。

- **合成を土台にする。** 録音は、合成で弱い所にだけ当てる（雪の鳴き、薪、器など）。全部を録音にはしない。世界の音がばらばらになる
- **使ってよいライセンス。** CC0（パブリックドメイン）を基本にする。CC BY は、作者名を credits に載せる前提で可。**NC（非商用）と ND（改変禁止）は使わない**（Steam で売る。音は切って加工する）。サイト独自の規約（効果音ラボ、Pixabay）は「商用可・ゲーム組み込み可・再配布は不可」を読んで、台帳に規約の URL と読んだ日を残す
- **台帳。** 録音を 1 つ入れるごとに [sound/SOURCES.md](../sound/SOURCES.md) に、ファイル名・出どころの URL・作者・ライセンス・取得日・どう加工したかを書く。台帳にない録音はリポジトリに入れない
- **生成サービス（ElevenLabs など）は使わない。** 生成物の権利の扱いが規約で変わる。合成で足りる
- **絵は変えない。** モデル・画像の「外の素材は使わない」は [アートコンセプト](art-concept.md) のまま

## 柱 1: ゲレンデのスピーカー

- 柱は登り道に沿って 6 本、麓から 30 m おき。頂上には置かない。登るほど曲は遠く細くなり、風が増える。滑り降りると柱を次々に追い越し、曲が戻ってくる
- 一本一本から同じ曲が届く。届くまでの時間は距離で違う（34 m で 0.1 秒）ので、立つ場所で重なり方が変わる。2 本の間で立ち止まると曲が二重に聞こえる
- スピーカーの音はラッパ型。残るのは 300 Hz〜3.5 kHz。1 kHz 付近が張り出し、2.5 kHz に鼻にかかった癖、小さなアンプが押している歪み。これが「あの細い音」
- 離れるほど小さく、高い音から先に細る（雪と空気が吸う）。本物より強めにかけ、60 m 先では 2 kHz より上がほとんど残らない
- 風で音量と高さがゆっくりうねる（10〜20 秒に 1 回）。柱ごとに位相が違うので、近づいたり遠のいたりが柱ごとに起きる
- 曲は、原型では「ゲレンデで流れていそうな軽い曲」を 8 小節のループで合成する。単純な音色でよい。本題はスピーカーを通した聞こえ方
- 日本のゲレンデの個性として売る。海外の人には珍しい

## 柱 2: 登り

- **足あと。** 一歩ごとに雪が「ギュッ」と鳴く。小さく短く。合成は代表が「気持ち悪い」と言ったので録音に差し替えた（[台帳](../sound/SOURCES.md)）。歩く 4 m/s で 1 秒に 2 歩、走ると 3 歩。押しているときは踏ん張りの歩で、長めに「ギュ…ッ」と上ずる。6 種を回して同じ音が続かないように
- まわりの人の足あとも鳴る。押す人数ぶん重なって、少しずつずれる。人が加わると音でもにぎやかになる
- **息。** 押している間だけ、吐く息。4 秒に 1 回から始まり、押し続けると 2 秒に 1 回まで速まる。苦しい音ではなく、働いている音。自分の息は耳元、人の息は距離で小さく
- **滑り木。** 速さで変わる。止まると無音。動き出すと連続した「しゃー」が薄く始まり、速くなるほど高く大きく。乗って滑る 8 m/s でいちばん高く大きい。止まりかけの「ざ、ざ」は作ったが、代表が要らないと言ったので外した（2026-10-27）
- ソリの木のきしみは、押す力が入った瞬間にまれに
- **風。** 麓は薄く、高いほど強い。頂上は風だけが残る

## 柱 3: 滑り出す一瞬

[ゲームの構想](game-concept.md)の「解放は全員で同じ一瞬に」を音で作る。

1. 乗る人がそろって、ソリが動き出す（1.5 m/s を超えた瞬間）
2. 外の音（スピーカー、足あと、風）が 0.3 秒で消える
3. 0.6 秒の無音。聞こえるのは自分の息ひとつ
4. 風が 0 から 1.5 秒かけて立ち上がる。滑り木の「しゃー」が速さについてくる
5. 柱を追い越すたびに、曲が近づいて遠のく
6. 止まると風が落ち、スピーカーの曲と足あとの世界に戻る

一人で滑り出しても同じ。みんなで乗ると、全員の画面で同じ瞬間に音が消える。

## 柱 4: ロッジの中

- 外から近づくと、窓から中の音（薪、食器）がかすかに漏れる。夕方の橙の窓の、音の版
- 風除室の戸は二重。一枚目を閉めると外が半分こもり、二枚目で中になる
- 中では外の曲がこもって遠くなる（600 Hz より上を落として −12 dB）。ガラス際では少し戻る
- 中の音は、炉の薪のはぜる音（1〜4 秒に 1 回「ぱち」、たまに大きく）、火の低い唸り、厨房の鍋の湯気と蓋、食器が触れる音、板の床の足音。2 階の畳では足音がほぼ消える
- 残響は短く（0.4 秒）、木の部屋。外が響かないぶん、ここで初めて「囲まれた」と分かる
- 手袋を外す切り替えに合わせて、音も素手の世界に。ここには雪の音がない

## 柱 5: 言葉と合図

- 言葉はない。合図は体の動きとスタンプと、言葉にならない声 3 つ（「ワ〜」「ウン」「ンーン」）
- 声は紙の人形の小さくやわらかい声。息を多めに混ぜ、高い倍音を落とす。人ごとに高さを少し変える（あなた 1.0、② 0.9、③ 1.18。Godot の pitch_scale）
- 身ぶりの音は短く乾いて小さい。ハイタッチはフェルトの手袋が合う「ぽふっ」、グータッチはその低い「こつん」、拍手はその小さいもの、雪玉づくりは雪の足あとの録音を高くして小さく（ぎゅっぎゅっと丸める音）、崩れる雪玉は「ぼすっ」、腕を振ると袖の「すっ」
- スタンプに音を付けるかは決めていない。代表に聞く（下）

## 釣り合い

大きい順。滑走の風 ＞ 自分の足あと・息・滑り木 ＞ 近くの人の足あと ＞ 柱の近くの曲 ＞ 遠い風 ＞ 遠い曲。ロッジの中は薪が中心で、全体に外より小さい。

## 作り方

- 効果音は Python（numpy・scipy。`sound/.venv`）で合成して 48 kHz の wav に。雪の足あとは狭い帯域の鳴きが短く上ずるもの（2026-10-27 に粒の重なりから作り直した。代表が「気持ち悪い、片栗粉の音に」）、風はフィルタしたノイズのうねり、滑り木は速さで帯域が動くノイズ、薪は散発の破裂、スピーカーはバンドパスとわずかな歪み
- 録音の切り出しは `sound/gen/cut.py`。元ファイルは `sound/raw/`（git に入れない）、出どころは [sound/SOURCES.md](../sound/SOURCES.md)
- 各 wav の波形とスペクトログラムを `sound/check/` に PNG で出し、形で確かめる（[一覧](../sound/check/summary.md)）。Claude は聞けないので、聞いた判断は代表がする
- ラッパ型の色付け（帯域・張り出し・歪み）は wav に焼き込む。Godot 側は距離の遅れ・高い音の減り・風のうねりだけを持つ
- Godot（`game/audio.gd`、2026-10-27 に入れた）。`main.gd` からは生成と `--spawn` の数行だけ
  - バス: Outdoor（外の音すべて。ロッジの中ではローパス 600 Hz と −12 dB）← Speaker（柱の曲）、Wind（風）。Inside（ロッジの中。短い残響。外からは壁ごしに 600 Hz でこもる）。Self（自分の足あと、戸）。設定画面の音量は `main.gd` が挿す Music（Speaker の先）・SFX（Inside と Self の先。Wind は音量だけ合わせる）・Voice（息。のちに声やスタンプの声）で効く。曲は Speaker、効果音は Self か Inside か Wind、息や声は Voice に通す。バスの名前は変えない
  - 柱は麓の外側、半径 44 m の輪に 6 本。曲は wav を 16 kHz に間引いて持ち、柱ごとに「聞く人との距離 ÷ 音速」だけ遅らせて生成ストリームに書く。遅れが距離で伸び縮みするので、追い越すときの高さの変化も出る。距離で高い音が先に細り（3.8 kHz から −30 dB）、ラッパの向きの外では −14 dB、風で ±3.5 dB うねる
  - 滑り木は「しゃー」の 1 本を速さで音量とピッチを変える。きしみは押している間にまれに
  - 風は薄いループを高さで、滑走のループを乗っているときの速さで。滑り出しは、乗った人がいて 1.5 m/s を超えた瞬間に Outdoor を 0.3 秒で −60 dB、0.35 秒後に息ひとつ、0.9 秒後から 1.6 秒で戻しつつ風のゲートを 1.5 秒で開く
  - 足あとは歩いた距離 2 m ごと（走ると少し長く）。押している間は 0.8〜1.1 秒ごとに踏ん張りの歩と、4 秒 → 2 秒へ速まる息。仲間も同じ仕組みで 3D に鳴る。ロッジの中では板の足あと
  - ロッジは位置で 3 つの区域（外・風除室・中）に分け、境を越えるとバスのこもり方を切り替えて戸の音を鳴らす。炉の目印に火の唸りとはぜる音、厨房に湯気と蓋、灯りの下に食器
  - 確かめ: `--log` の各行に「音:」として区域・風・滑り木・近い柱の距離と遅れ・ゲートが出る。`--spawn=lodge` で風除室の前から、`--spawn=inside` で食堂の中から始められる
  - まだ: ロッジの戸は自動の引き戸になったので、いまの木の戸の音は仮。スタンプの音は代表の判断待ち。乗った人数が「そろった」判定は、いまは「乗っている人がいて動き出した」だけ

## 代表に聞くこと

1. この音の世界でよいか。特に、BGM なし・画面の音なし・声なし
2. スタンプの音。(a) 無音。見て気づく。(b) 紙がこすれるくらいの小さな音。紙の体の人が出す音として
3. 曲の作り方。原型は合成の短いループで進める。本番の曲は、コードで作曲を続けるか、生成モデル（ACE-Step など。GPU が要るので承認が要る。始めていない）か、人に頼むか
