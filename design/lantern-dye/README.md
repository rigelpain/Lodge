# ランタンの選びを覚える・ランタンの色替え（2026-11-10）

代表「あと起動時にランタン持ってないの困るからどのランタンを設定してるか保持していてほしい。あとCPUのランタンの色変わってるけどプレイヤーもできる？なかったら紙細工師さんで色変え売って欲しい。」

- 01 → 04: 夜、和紙の提灯（もとの色）→ 紙細工屋さんで青緑に染めたあと
- 02 → 03: 紙細工屋さんの 2 段目「色替え」。いま提げているランタンを、キャラの色のパレット 12 色で灯した札（6 × 2）。左上は布の色、左下の丸い布はもとの色に戻す（ただ）
- 05: 起動し直したあと。和紙の提灯を青緑で提げたまま
- 撮り方: game/tools/lantern_keep_check.gd（--part=save → --part=load）
