# ロッジの施設（作る・買う・強くする）の研究

2026-10-28 の調べ。ゲームでよくある「アップグレードや報酬を象徴する施設」を、Lodge ではどう作るか。モチーフ元を広げ、形・動き・強化の見せ方を考える。まだ決定ではない。

いまある施設は 4 つ。大きなミシン（ソリ・服を縫う）、アイロン台（焼く）、服のプレス機（押す）、乾燥機（あたためる）。模型は `props/build_machines.py` と `props/build_kitchen.py`。

## 守ること（柱から）

[ゲームデザインの骨組み](game-design.md) の柱 5 本を、施設に当てはめる。

| 柱 | 施設での形 |
|---|---|
| 1 言葉なしで通じ合う | 何の施設かは、形と動きと音で分かる。文字の看板は使わない。材料と出来上がりは、棚に置いた実物とアイコン・矢印で見せる |
| 2 長い期待、一瞬の解放 | 作るときは「ため → 一瞬の解放 → 見せる」。ソリの登りと滑りの縮図にする |
| 3 邪魔できるのに、しない | 人が使っている機械を止めたり、横取りしたりは、できる。でも、しないほうが楽しい作りにする |
| 4 ロッジでゆるむ | 待つ間も眺めていて気持ちいい。急かさない。長い待ちは作らない |
| 5 手でさわる手芸の世界 | 布・糸を扱う本物の道具から形を借りる。ぬいぐるみの機械（ふっくらしたフェルトの箱を縫い合わせる） |

もう一つ、ソリの手ざわりと同じ決まりを施設にも使う。**一人でも使えるが、人が加わるほど目に見えて速くなる。** 足踏みとハンドルを分けて 2 人で動かすと、ミシンが速く回る、など。

## ほかのゲームから学んだ型

14 本の例を調べた（タヌキ商店と博物館（あつ森）、Stardew Valley の鍛冶屋と大工、モンハンの加工屋、Hades の館、Spiritfarer の船、DREDGE、Moonlighter、Valheim の作業台、Slime Rancher、ブレワイの大妖精の泉、Cult of the Lamb、Lethal Company）。共通して効いていたこと:

- **遠くから分かる形**: 煙突、炉、大きな道具（槌、つぼみ）。形だけで「ここで何をするか」が分かる
- **育つ見た目は 3 通り**:
  - 同じ形のまま大きくなる（タヌキ商店、鶏小屋）
  - 周りに道具が増える（Valheim は作業台の 2 m 以内に置いた道具の数で段階が上がる）
  - 中の陳列が埋まる（博物館、Moonlighter）
- **ため → 解放**: 槌で数回たたく → 割れる、つぼみがふくらむ → 開く。解放の瞬間に音と粒とごく短い止め（ヒットストップ）
- **品を掲げて見せる**: できた物を高く掲げる、空から降りてくる（Lethal Company の降下船）。手に入れた瞬間がみんなの出来事になる
- **待ち時間**: 一人用は「翌日に完成」で、また来る理由にしている。協力ゲームでは長い待ちは嫌われる（降下船を飛ばす MOD が多い）
- **協力**: 作業している人が周りから見える（Overcooked、Deep Rock Galactic）。置いた物が全員の段階を上げる（Valheim）

色だけの段階差（銅 → 金）は、フェルトの柔らかい色の中では伝わりにくい。段階の差は、形・大きさ・部品の数で出す（推測）。

## モチーフの候補（布・糸の道具）

40 ほど集めた中から、動きで分ける。

| 動き | 道具 |
|---|---|
| 回す | 糸車（大車輪）、チャルカ、ドラムカーダー（綿を梳く）、綿繰り機、座繰り器、かせくり器・玉巻き器、手回し靴下編み機、マングル |
| 往復 | 横編み機のキャリッジ、杼（飛び杼）、ミュール紡績機の台車 |
| 上下・連打 | 刺繍ミシン、ニードルフェルト機、足踏み板 |
| 打つ | 縮絨の木槌、ウォーキング（台を囲んで歌いながら布を打つ）、ハトメ打ち、筬の打ち込み、綿打ち弓 |
| 押す | くるみボタンのプレス、タグガン、木版のはんこ |
| 巻く | ボビンワインダー、反物の巻き台、キルト枠の巻き取り |
| 張る | テンター、伸子、キルト枠、刺繍枠 |
| 送り続ける | ジャカード織機のパンチカード、検反機 |
| 浸す・煮る | 藍甕、染めの釜、バティックの蝋の鍋 |
| 持ち替える | 組紐の丸台、ボビンレース |

施設として強いと見た 8 つ（形が象徴的・動きが楽しい・何人かで動かせる・いまの 4 つと役目が重ならない）:

1. **ジャカード織機**: 高い塔と、穴あきカードの鎖が回る形はほかにない。カード 1 枚 = 柄 1 つにすれば、柄を集める報酬にそのままなる
2. **糸車（大車輪）**: 大きな丸い車輪は遠くから分かる。回す人と糸を引く人で協力
3. **ウォーキング台（縮絨）**: 台を囲んで、拍に合わせてみんなで布を打つ。道具の成り立ちそのものが協力
4. **マングル**: 鋳鉄の門形の枠と大きなはずみ車。2 人で大ハンドルを回す。プレス機の「上から押す」と違う「通して平たくする」
5. **キルト枠**: 近所の人が集まって一緒に縫う道具（キルティング・ビー）。休む・人を呼ぶ施設に意味がぴったり
6. **組紐の丸台**: 丸い台に色とりどりの玉が垂れる、かわいい形。ソリの綱の強化に直接つながる
7. **藍甕・染めの釜**: 泡と湯気、浸すと色が変わる。結果がひと目で分かる
8. **手回し靴下編み機**: 円筒とハンドル、下へ伸びる編み地。回すほど伸びるので成果が目に見える

次点: 刺繍ミシン（エンブレム・飾り）、くるみボタンのプレス（ボタンをお金にする）、トルソー（服の店の看板）、座繰り器・ガラ紡（日本らしさと音）。

調べた出典は主に Wikipedia の各項目（糸車、ジャカード織機、Fulling・Waulking、Mangle、Kumihimo、Quilting、Circular knitting など）と、各ゲームの wiki・攻略記事。動きや音の細部は記憶によるものが多いので、作るときに確かめる。

### 代表が足した候補（2026-10-28）

刺繍、タフティング、機織り機、絞り染め、紙漉き。5 つとも強い。しかも刺繍以外の 4 つには、**伏せて作り、最後に一気に見せる**工程がある。柱 2「長い期待、一瞬の解放」の「解放」を、道具そのものが持っている。

| 道具 | 作るもの | 動き | 解放の瞬間 | 協力 |
|---|---|---|---|---|
| **紙漉き** | 紙の体（キャラ）、色紙、手紙 | 簀桁（すけた）で槽の紙料をすくい、縦横に揺する。引き上げると水がしたたる | 乾いた紙を板から一気にはがす | 大判の紙は 2 人で簀桁を持って揺する |
| **タフティング** | ラグ・マット、ソリの座布団、ロッジの床 | ガンを布に当てて「ドドド」と打ち込む。張った布の裏から打つ | 枠ごと裏返すと、表にふわふわの絵が現れる | 打つ人と、図案を描く・糸を替える人 |
| **絞り染め** | 一点ものの柄の布・服 | 布を糸で縛る・つまむ・畳む → 染め甕に浸して引き上げる | 糸をほどくと柄が開く。毎回少し違う | 縛る人と浸す人。みんなで同時にほどく |
| **機織り機（手機）** | 布そのもの（ほかの施設の材料） | 足で踏み木、杼を左右に飛ばし、筬で「トントン」と打ち込む | 織り上がった布を機から切り落とし、巻きをほどく | 踏む・杼を飛ばす・打つの 3 役 |
| **刺繍（刺繍枠・刺繍ミシン）** | 自分の印（ワッペン・エンブレム）、服の飾り | 枠が縦横に動き、針が連打して模様が浮かぶ | 枠から布を外して、服やソリに縫い付ける | 色糸を替える人と、枠を動かす人 |

それぞれが特に効く所:

- **紙漉き**は、この世界にいちばん深くつながる。キャラは紙の体なので、紙漉きは「体を作る・作り直す・着せ替える」施設になる。濡れた紙を暖炉で乾かすアイデア（[ゲームの構想](game-concept.md) の「休むと乾く」）とも続いている。漉く → 張る → 乾かす → はがす、と工程が長く、ロッジで過ごす時間に向く
- **タフティング**は、裏返したときの驚きがいちばん大きい。ガンの打ち込みは見ていて気持ちよく、音も強い。できたラグはロッジの床に敷けるので、みんなで育てた景色になる
- **絞り染め**は、ほどくまで柄が分からない。偶然があるので、同じ材料でも一点ものになる。たくさんの柄をストックする方針（滑りあとの柄など）に合う。藍甕と組にすると、藍甕は単色、絞りは柄、と役目が分かれる
- **機織り機**は、ほかの施設の材料（布）を生む根っこ。強化でジャカードの塔が乗る（「強化の見せ方」の節）
- **刺繍**は、言葉の代わりの名札になる。名前を出さないゲームで、自分の印を服やソリに付けて「さっきの人だ」と分かる。柱 1「言葉なしで通じ合う」に効く

## 施設の並びの案

いまの 4 つに足すなら、ロッジの中で役目がこう分かれる。

| 役目 | 施設（モチーフ） | 作る・変えるもの |
|---|---|---|
| 布を織る | 機織り機（手機） | ほかの施設で使う布。強化でジャカードになる |
| ソリ・服を縫う | 大きなミシン（いま） | ソリ本体、上着 |
| 小物を編む | 手回し靴下編み機 | 帽子・手袋・マフラー |
| 体を作る | 紙漉き | 紙の体の作り直し・着せ替え、色紙、手紙 |
| 敷く・座る | タフティング | ラグ、マット、ソリの座布団 |
| 柄を決める | ジャカード織機 | 滑りあとの柄、服の柄。パンチカードを集めると柄が増える |
| 一点ものの柄 | 絞り染め | ほどくまで分からない柄の布・服 |
| 自分の印 | 刺繍 | 名札の代わりのワッペン・エンブレム |
| 色を変える | 藍甕・染めの釜 | ソリと服の色 |
| 綱を強くする | 組紐の丸台 | ソリの引き紐の見た目と長さ |
| 焼く | アイロン台（いま） | 焼き物 |
| 押す | 服のプレス機（いま） | 押して作るもの |
| あたためる | 乾燥機（いま） | あたため物 |
| のばす | マングル | 生地をのばすもの（クッキー、麺） |
| 揚げる（未定だった所） | バティックの蝋の鍋 | 熱い蝋の鍋を油の鍋に見立てる。布を熱で扱う道具なので筋が通る |
| 休む・集まる | キルト枠 | 座って一緒に縫うと、休むのが早まる |

「強くする（アップグレード）」は、施設を足すのではなく、**施設そのものが育つ**ことで見せる（次の節）。お金をボタンにして、くるみボタンのプレスで両替する案もある（通貨を決めるときに考える）。

## 施設をアイコニックにする形の決まり

- **一つの部分を大げさにする**: ミシンなら針と糸巻き、糸車なら車輪、ジャカードならカードの鎖。窓の外から見ても、その一つで分かる
- **動く所を外に出す**: 歯車・ベルト・はずみ車は箱にしまわず、見えるようにする（中の仕組みが動いて見えるのが楽しい）
- **ぬいぐるみの機械**: ふっくらしたフェルトの箱に、縫い合わせの耳をかがる（いまのミシンの作り方）。金属の所は木か、色を落ち着けたフェルトで
- **棚の手本**: 施設の横の棚に、材料 → 矢印 → 出来上がりの実物を並べる。文字の代わり
- **人の背丈との比**: 人（1.6 m）がのぞきこむ大きさ。2 人以上で動かす施設は、取っ手やペダルが離れて 2 か所にある

## 強化（アップグレード）の見せ方

Valheim 式に、**実物の部品が周りに増えていく**。段階ごとに形が変わり、遠くから見ても何段目か分かる。

大きなミシンの例:

| 段階 | 見た目 | 効き目の例 |
|---|---|---|
| 1 | 卓上のミシン（いま） | 小さいソリ、基本の服 |
| 2 | 鋳鉄風の足踏み台に載る。足踏み板と大きなはずみ車が付く | 中くらいのソリ。踏む人が加わると速く縫える |
| 3 | 上に糸巻きの塔、横にボビンの列、針山、手もとのランプ | 大きいソリ、凝った服 |
| 4 | 布送りの台が前へ長く伸び、できたソリがそのまま滑り出られる | いちばん大きいソリ |

ほかの施設も同じ考え方で:

- 糸車 → 紡錘がずらりと並ぶ（ジェニー紡績機）→ 筒が上下するガラ紡
- 手機 → ジャカードの塔が乗る → カードの鎖が長くなる
- 藍甕が 1 つ → 2 つ、3 つと並び、色の数が増える

ロッジそのものも育てる。煙突の毛糸の煙、旗、窓の明かりなど外から見える目印を足して、「みんなで育てた」ことを景色にする。

## 施設の動き（モーション）

一つの施設の動きを、7 つの場面に分けて作る。

| 場面 | 何をするか | 例（大きなミシン） |
|---|---|---|
| 待つ | 誰も使っていない。ゆっくり息をするように動く | 糸巻きがときどき半回転、ランプがゆらぐ |
| 呼ぶ | 人が近づくと気づく | 針が持ち上がり、布送りの歯が一度カタッと動く |
| 入れる | 材料を入れる | 布が吸い込まれ、糸がぴんと張る |
| ため | 作業が進む。だんだん速く、音が高く | 針の上下が速くなり、布が送られ、糸巻きが回る（1〜3 秒） |
| 解放 | できあがる一瞬 | 糸を切る「パチン」、ごく短い止め、綿くずの粒がふわっと舞う |
| 見せる | できた物をみんなの前に出す | ソリが布送りに乗って滑り出て、前で止まる。服は吊るし台に掛かって揺れる |
| 余韻 | 元に戻る | 針がゆっくり止まり、糸巻きの回転が落ちる |

- **待ち時間は短く**。「ため」は数秒。長くかかる物は、ためを何回かに分けて、そのたびに部分が見える（袖が付く、など）
- **できた物の受け取りは全員の出来事にする**。たとえば天井から、紙の箱が糸で吊り降りてくる
- **動きで中の状態を伝える**。湯気が上がる、ふたが閉まる、回る、止まる、「ぽん」と出る。言葉なしの合図になる
- **音は手芸の音でそろえる**。ミシンの連打、はさみ、アイロンの蒸気、組紐の玉が当たる「カチ、コツ」。音だけで施設が分かる
- **コマ撮りにするか**: ストップモーション（12 fps）は、いまはキャラだけの決まり。機械も 12 fps にすると世界がそろうが、なめらかに回る車輪の気持ちよさは減る。試して決める

## 協力と「邪魔できるのに、しない」

- 2 人で動かす所を作る（足踏みと布送り、大ハンドルの両側、ウォーキングの拍）。一人でも使えるが、2 人だと目に見えて速い
- 誰かが使っている機械は、周りから見える所に置く。作っているのを眺めるのも楽しい
- ほかの人の車輪を止める、材料を抜く、などはできる。しないことが規範になる（ソリと同じ）

## 将来の案: 巨大な温度計（2026-10-30、代表の案）

- ロッジに置く、巨大な温度計。チャコペン（布に印を付けるペン）のモチーフ。軸が目盛りになり、ペン先のチャコ（粉）の色が上がり下がりして、いまの気温を指す
- 指す値は気温の仕組み（`game/temperature.gd`）。ロッジの中の温度計なら外の気温（扉の外、または頂上）を指すと、出かける前に寒さが分かる。吹雪の天気ができたら、その寒さも指す
- まだ作らない。置き場（ロッジの壁か、扉の脇）と、文字を使わない目盛り（雪の結晶・炎の印など）は、作るときに決める

## 次に決めること

1. 施設をいくつ、どの順に入れるか（まずはいまの 4 つ＋何を 1〜2 つ。紙の体とつながる紙漉きが第一候補）
2. お金を何にするか（ボタン案）と、強化に払うもの
3. 施設もコマ撮りにするか（ミシン 1 台で 12 fps となめらかを見比べる）
4. 大きなミシンで「7 つの場面」の動きを 1 本試作し、手ざわりを確かめる → 試作した（2026-10-28、[sewing-motion](sewing-motion/README.md)）。代表はコマ撮り版を選んだ。動く所とできる物は大きくした。12 fps では 1 秒に 6 回より速い動きが読めないので、針の速さは 5.5 回／秒まで
