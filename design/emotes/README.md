# 手と身ぶり（エモート）の絵

`game/tools/emote_shots.gd` で撮った確かめの絵（2026-10-28）。決まりは [アートコンセプト](../art-concept.md) の「手と身ぶり」。

名前は `身ぶり_視点.jpg`（撮る道具は png で書き出すので、入れるときに JPEG にした）。視点は 3 つ。

- `fp` 一人称（あなたの目）。自分の手袋・雪玉・手のひら・白い息が画面に見えるか
- `tp` 三人称（C の視点）
- `front` 横の少し前から（人形の形と、二人の手が合う所）

| 名前 | 何のコマか |
|---|---|
| `ring` | Tab の輪（左上の指さしを選んでいる。まんなかに、いまの手） |
| `high_R` `high_L` `high_both` | 高い手のひら（右手・左手・両手） |
| `high_both_up` | 高い両手のひらで見上げる（万歳） |
| `low_R` `low_both` | 低い手のひら（おさえて・ストップ） |
| `point_R` `point_both` | 指さし（右手・両腕） |
| `five_pull` / `five_11` / `five_burst` | 高い片手のひら同士で近づいて、引く → 叩きつける（紙の星）→ 紙吹雪 |
| `five_12` / `five_22` | ハイタッチ: あなたの片手と仲間の両手 / 両手どうし |
| `shake_11` / `shake_12` / `shake_22` | 握手: 片手どうし / 片手を両手で包む / 両手どうし |
| `whiff` | 仲間がよそを向いたまま寄って、空振り |
| `clap` | 高い両手のひらで左クリック |
| `breath_in` / `breath_out` | B を押した瞬間に吸う所と、押したまま長く吐く所 |
| `crouch` / `make_ball` | 左 Ctrl でしゃがむ、雪面を見て F で雪玉を丸める |
| `windup` / `throw` | 左クリックを押してためる、離して投げる |
| `hit_bot` / `hit_me` | 雪玉が仲間に当たる／あなたに当たる（のけぞる） |
| `sled` | ソリに当たって、綿の雪が残る |
| `un` / `nn` / `huh` / `oi` | 声「ウン」「ンーン」「ウン？」「おーーーい」の身ぶり（`huh` は首をかしげる、`oi` は口に手を当てて呼ぶ） |
| `banzai` | ソリの上で高い両手のひらを掲げて見上げる |

撮り直すには（`--only=hand_up,high_five` で一部だけ）:

```bash
/Applications/Godot.app/Contents/MacOS/Godot --path game --resolution 960x540 -s res://tools/emote_shots.gd -- --bots=1 --no-sound --no-pip --no-snow --view=fp --dir="$PWD/design/emotes"
```

仲間の返し（ハイタッチ・握手に来る・声を返す・ウン？にウン・拍手を返す）は `--check` で、撮らずに出来事の記録で確かめる。

## 声

声は `sound/gen/voice.py` で合成した（録音も生成サービスも使っていない）。波形とスペクトログラムは `sound/check/voice_*.png`。

どれも 01 がふつう、02 が全体に高い声、03 が全体に低い声（上がり下がりの形は同じ。口の響きも一緒に上げ下げして、小さな体・大きな体の声に）。ゲームでは人形ごとに 1 つに決めている（あなた = 01、背の高い折り紙 = 03、いちばん小さい新聞紙 = 02）。

| 声 | ファイル | 長さ | 高さ（01 / 02 / 03） |
|---|---|---|---|
| ワ〜 | `sound/wav/voice_wa_01..03.wav` | 0.74〜0.84 秒 | 290→375 Hz / 380→520 Hz / 195→245 Hz（上がって下りる） |
| ウン | `sound/wav/voice_un_01..03.wav` | 0.31〜0.33 秒 | 300→235 Hz / 395→325 Hz / 200→160 Hz（短く下がる） |
| ンーン | `sound/wav/voice_nn_01..03.wav` | 0.61〜0.65 秒 | 320→220 Hz / 480→320 Hz / 170→120 Hz（山のあと一度切れて下がる） |
| ウン？ | `sound/wav/voice_unq_01..03.wav` | 0.41〜0.44 秒 | 275→370 Hz / 360→485 Hz / 180→235 Hz（少し沈んで、後半で上がる） |
| おーーーい | `sound/wav/voice_oi_01..03.wav` | 1.27〜1.37 秒 | 伸ばし 325 Hz→語尾 255 Hz / 435→335 Hz / 228→175 Hz（高めで平らに伸ばし、最後の い で約 4 半音下がる。2026-10-31、代表の言葉「さいご上がるのでなく下がるべき」で直した） |
| びっくり | `sound/wav/voice_surprise_01..03.wav` | 0.31〜0.33 秒 | 540 Hz / 640 Hz / 380 Hz へ跳ねて落ちる（息をのむかすれのあと） |

聞き方: `sound/check/listen.html` をブラウザで開くと、波形とスペクトログラムを見ながら再生できる（`voice_`・`felt_pat_`・`snow_splat_`・`swish_` が今回の音）。Finder で `sound/wav/` のファイルを選んでスペースキーでも鳴る。ゲームの中では、ウン・ンーン・ウン？・おーーーいは 4・5・6・7 キーか輪、ワ〜は滑りながら高い両手のひらにしたとき、びっくりは雪玉が当たったとき。人形ごとに声の大きさが違う（上のとおり）。合成なので、やわらかさ・人形らしさは代表の耳で判断してほしい。
