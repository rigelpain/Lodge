# 手と身ぶり（エモート）の絵

`game/tools/emote_shots.gd` で撮った確かめの絵（2026-10-28）。決まりは [アートコンセプト](../art-concept.md) の「手と身ぶり」。

名前は `身ぶり_視点.jpg`（撮る道具は png で書き出すので、入れるときに JPEG にした）。視点は 3 つ。

- `fp` 一人称（あなたの目）。自分の手袋・雪玉・手のひら・白い息が画面に見えるか
- `tp` 三人称（C の視点）
- `front` 横の少し前から（人形の形と、二人の手が合う所）

| 名前 | 何のコマか |
|---|---|
| `ring` | Tab の輪（左上の指さしを選んでいる。まんなかに、いまの手） |
| `high_R` `high_L` `high_both` | 高い手のひら（右手・左手・両手） |
| `high_both_up` | 高い両手のひらで見上げる（万歳） |
| `low_R` `low_both` | 低い手のひら（おさえて・ストップ） |
| `point_R` `point_both` | 指さし（右手・両腕） |
| `five_pull` / `five_11` / `five_burst` | 高い片手のひら同士で近づいて、引く → 叩きつける（紙の星）→ 紙吹雪 |
| `five_12` / `five_22` | ハイタッチ: あなたの片手と仲間の両手 / 両手どうし |
| `shake_11` / `shake_12` / `shake_22` | 握手: 片手どうし / 片手を両手で包む / 両手どうし |
| `whiff` | 仲間がよそを向いたまま寄って、空振り |
| `clap` | 高い両手のひらで左クリック |
| `breath_in` / `breath_out` | B を押した瞬間に吸う所と、押したまま長く吐く所 |
| `crouch` / `make_ball` | 左 Ctrl でしゃがむ、雪面を見て F で雪玉を丸める |
| `windup` / `throw` | 左クリックを押してためる、離して投げる |
| `hit_bot` / `hit_me` | 雪玉が仲間に当たる／あなたに当たる（のけぞる） |
| `sled` | ソリに当たって、綿の雪が残る |
| `un` / `nn` / `huh` / `oi` | 声「ウン」「ンーン」「ウン？」「おーーーい」の身ぶり（`huh` は首をかしげる、`oi` は口に手を当てて呼ぶ） |
| `banzai` | ソリの上で高い両手のひらを掲げて見上げる |

撮り直すには（`--only=hand_up,high_five` で一部だけ）:

```bash
/Applications/Godot.app/Contents/MacOS/Godot --path game --resolution 960x540 -s res://tools/emote_shots.gd -- --bots=1 --no-sound --no-pip --no-snow --view=fp --dir="$PWD/design/emotes"
```

仲間の返し（ハイタッチ・握手に来る・声を返す・ウン？にウン・拍手を返す）は `--check` で、撮らずに出来事の記録で確かめる。

## 声

声は `sound/gen/voice.py` で合成した（録音も生成サービスも使っていない）。波形とスペクトログラムは `sound/check/voice_*.png`。

声の高さと声色は `game/doll.gd` の `VOICE` で人形ごとに決める（代表の言葉、2026-10-31）。いまの 3 体は性別と身長で決める（女性で背が低いほど高く、男性で背が高いほど低い）: kasa（あなた、女性、1.58 m）を 1.0 に、origami（女性、1.64 m）は 0.97、news（男性、1.00 m）は 0.84。まだゲームにいない 4 体は代表が高さと声色を決めた: robo 0.9（真ん中、ロボット）、musha 0.75（低め、鋭い）、ningyo 1.15（高め、丸い）、golem 0.55（いちばん低い、獣のカタコト）。口の響きも体の大きさについていく。人形どうしで長さと抑揚は同じ

| 声 | ファイル | 長さ | 高さの中ほど Hz（kasa / origami / news / robo / musha / ningyo / golem） |
|---|---|---|---|
| ワ〜 | `sound/wav/voice_wa_<人形>.wav` | 0.75 秒 | 338 / 329 / 284 / 309 / 254 / 389 / 176 （上がって下りる） |
| ウン | `sound/wav/voice_un_<人形>.wav` | 0.31 秒 | 274 / 268 / 232 / 240 / 207 / 314 / 152 （短く下がる） |
| ンーン | `sound/wav/voice_nn_<人形>.wav` | 0.61 秒 | 257 / 251 / 216 / 230 / 191 / 294 / 142 （山のあと一度切れて下がる） |
| ウン？ | `sound/wav/voice_unq_<人形>.wav` | 0.41 秒 | 276 / 268 / 232 / 247 / 207 / 319 / 152 （少し沈んで、後半で上がる） |
| おーーーい | `sound/wav/voice_oi_<人形>.wav` | 1.36 秒 | 322 / 314 / 271 / 291 / 241 / 371 / 176 （高めで平らに伸ばし、最後の い で約 4 半音下がる。2026-10-31、代表の言葉「さいご上がるのでなく下がるべき」で直した） |
| びっくり | `sound/wav/voice_surprise_<人形>.wav` | 0.32 秒 | 480 / 471 / 393 / 455 / 368 / 533 / 279 へ跳ねて落ちる（息をのむかすれのあと） |

聞き方: `sound/check/listen.html` をブラウザで開くと、波形とスペクトログラムを見ながら再生できる（`voice_`・`felt_pat_`・`snow_splat_`・`swish_` が今回の音）。Finder で `sound/wav/` のファイルを選んでスペースキーでも鳴る。ゲームの中では、ウン・ンーン・ウン？・おーーーいは 4・5・6・7 キーか輪、ワ〜は滑りながら高い両手のひらにしたとき、びっくりは雪玉が当たったとき。人形ごとに声の高さが違う（上のとおり）。合成なので、やわらかさ・人形らしさは代表の耳で判断してほしい。
