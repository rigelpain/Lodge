# 黒いランタンは、まわりを暗くする（2026-11-10）

代表「ランタンの染色ですが、黒いランタンは逆に周囲を暗くするようにしてほしいです。」「最も強くしてほしいし、暗くする範囲は床でなく…球状に暗くしてほしい」「キャラ中心じゃなくてランタン中心だ」「黒ランタンは相対的な暗さでなく絶対的な暗さにしてほしい」

どの絵も、左が黒に染めた和紙の提灯、右がもとの色の和紙の提灯（どちらも点けている）。
