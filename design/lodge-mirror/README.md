# 入口の横の大きな鏡（2026-11-04）

代表「染色台の左、ロッジ入口の内側のすぐ横の壁に天井までの高さの大きな鏡を置いてほしい。染色やカスタムした自キャラをまじまじと大きく見たい。なので、鏡前に立ってFでインタラクトしたら鏡に自分のキャラを前から見たのが移り、刺繍より何倍も大きく拡大して見えるようにしたい。拡大して描写するのはキャラのみでOK」「アクセサリとミニオンも含めた自キャラね」。

## 決めたこと（代表の確認待ちは 2 つ）

- 置き場: 1 階の南の壁の内の面。枠の外で x -18.25〜-15.15、幅 3.1 m、高さは床から天井まで 5.25 m。鏡の面は 2.56 × 4.55 m。自動ドアの額縁（x -14.98）との間 0.17 m、桶とのあいだは人の太さで通れる
- **枠（代表の確認待ち）**: 3 案のうち、A 大きな刺繍枠で組んだ。右下の小窓と同じ造形で「小窓の大きい版」とわかるため。B・C に替えるなら `ideas.py` の `--what` と `game/mirror.gd` の `SURFACE` を替える
- 鏡の面: ガラスにせず、銀糸を織り込んだ布（ラメ）。ゆるいしわ、織り目、見る向きできらっとする細かな点
- 左右: 本物の鏡のとおりに反転する（右手を上げると、鏡の同じ側の手が上がる）
- 映り方: カメラは人形から鏡の真ん中へ向かう向きの先。鏡の方を向けばいつも前から映り、見回すと人形の向きのとおりに斜めからの姿も見える
- 映す物: 自分の人形・頭と肩の小物・手に持った物・手形・自分のミニオン。ほかの人・ロッジ・地面は映さない。足もとには薄い丸い影だけ落とす
- **ミニオン（代表の確認待ち）**: ふだんロッジの中では暖炉の前で寝ている。映しているあいだは、本物が足もとへ駆けてきて、鏡の方を向いて座る（遠ければ背後へ跳んでから走るので、約 1 秒で着く）。消すと暖炉へ帰る。呼ぶのはこの画面だけ（通信では送らない）で、ほかの人の画面では暖炉の前のまま
- 顔: 大きな鏡の高い所にある顔を見上げても、鏡の中の顔がのけぞらないよう、映っているあいだは人形の上下の見る向きの効きを 2 割にする（自分の画面だけ）

## 作り

- 形: `ideas.py`（Blender）。`--what A --export game/props/lodge_mirror` で枠の glb を書き出す。鏡の面はゲームが足す
- ゲーム: `game/mirror.gd`。置く所は `main.gd` の `MIRROR_AT`、F は `player.gd` の `_mirror_f`（映したまま桶や人形や紙細工屋さんを向いて F を押せば、そちらが開く）、案内は `hud.gd` と `hud_icons.gd` の `_mirror`、ミニオンは `companions.gd` の `mirror`
- 描き方: SubViewport（788 × 1400 px、小窓の 6 倍あまり）で 2 コマに 1 回。初めて映すときに作り、消えたら止める。環境は環境光の色だけ。層は自分の体（層 2）と鏡だけの層 11
- 明るさ: 太陽と月は鏡のカメラに当てない（屋根を描かないので、屋根の影が落ちず、中の人形に日が当たってしまう）。ロッジの灯りに鏡の側からの灯りを足す。トーンマップは本体の画面で一度だけ
- 確かめ: `game/tools/mirror_shots.gd`（`--part=look|dolls|color|fps|pass|net`）

## 測った値

- fps（1920×1080、この Mac、ロッジの中）: 映していないとき 21.2・19.8、映しているとき 19.1・19.0
- 全身: 7 体とも、立ち姿も両手を上げた姿も絵の縁に触れない（小物とポニーを付けて）
- 通り道（人の太さ 0.7 m の当たりで）: 枠と桶のあいだ、入口のマットから食堂、入口から人台の正面、いずれも通れる
