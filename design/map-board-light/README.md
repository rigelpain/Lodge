決めたこと:

- **器具**: 額の上の左右の端から木の腕を 2 本、手前の斜め上へ出し、下屋と同じ紙と木の提灯（`pendant_lantern.glb`）を提げる。下屋より少し小さい 1.1 倍
- **置き場**: はじめは額の真ん中寄りで、丘と大山の真上に被っていた（代表「提灯地図に被って見づらい。もっと端っこか上にしてほしい」）。端へ寄せ、提灯の下の端が額より上に来る高さにして、光は看板の真ん中の側へ向けた
- **光の色**: ロッジの灯りより白い `(1.0, 0.93, 0.82)`。ロッジと同じ橙にすると藍の布が黒く沈み、黄の布も橙に見えた。提灯の紙の色はロッジの灯りのまま
- **時刻**: 下屋の灯りと同じ決まり（`daylight()` と `DAY_ON`）。昼は灯りごと消えるので白く飛ばない。日が傾くと点く
- **当てる物**: 看板の面・額・まち針・提灯だけ（見た目の層 18 と `light_cull_mask`）。影がない灯りは看板を通り抜けて裏の雪まで照らすのを防ぎ、広い雪の計算も省く。そのぶん足もとの雪に光のたまりはできない
- **まち針**: 灯りは上から当たり、人は下から見上げるので、玉の下側が黒く沈んでいた。`backlight` で裏へも光を回した
- **重さ**: 影なしの SpotLight3D が 2 つ。昼は消え、70〜80 m で薄くなって消える。提灯の形は 90 m で描くのをやめる

確かめ: `game/tools/map_light_shots.gd`（`--fps` で灯りの有無を交互に測る）
