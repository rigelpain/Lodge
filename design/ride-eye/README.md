# ソリに乗ったときの目線と、連れの子狐の座る所（2026-10-28）

代表の声：「ソリに乗ったとき視点がだいぶ高いので、ちゃんとキャラの目線になるようにしてほしい。あとペットがソリ前方の宙に浮いてるので、キャラの膝というか、すぐ前に座らせてほしい」

## 目線

- 乗っているときの一人称のカメラを、**座った人形の目の所**に置く。立っているときの 1.55 m のままだったので、座った人形より 1 m ほど高かった。
- 目の所は人形ごとに持つ（`doll.gd` の `EYE`）。座るときに腰を落とす量（`_sit_drop()`）を引くので、どの人形でも、どの席でも合う。笠の人形は席から 0.61 m。
- ソリが傾けば、目も一緒に傾く。乗り降りは、カメラの位置を前と同じ速さで寄せるので、すっと腰を下ろし、すっと立ち上がる。

## 連れの子狐

- 乗っているあいだは、持ち主の**膝の前の座面**に座る（`companions.gd` の `LAP`。持ち主の席から前へ 0.34 m、右へ 0.2 m）。
- 所と向きはソリの座標で持つので、ソリが滑っても、跳ねても、傾いても離れない。坂を 5.4 m/s で滑らせて測ったずれは、最大 1.2 cm（乗った直後に跳び移る分）。
- 子狐は大きい（座って 0.65 m）ので、まん中に座らせると一人称の前がふさがる。右へ少し寄せて、前の雪が見えるようにした。乗っているあいだは、行く先を見る。
