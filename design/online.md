# オンラインで一緒に遊ぶ（テストプレイ用）

2026-11-01 に書いた。友達とオンラインでテストプレイするための方針と、いまの作り。

## 方針

- Godot の高レベルの multiplayer（ENet）を使う。一人がホストになり、ほかの人がホストへつなぐ。
- サーバーは借りない。ホストの Mac か PC が、そのままサーバーになる。
- 合わせて 8 人まで（ホストと、つなぐ人 7 人）。人形が 7 体なので、それに合わせた。

## つなぎ方の比較

| つなぎ方 | 準備 | 費用 | よいところ | 困るところ |
|---|---|---|---|---|
| **Tailscale（おすすめ）** | みんなが Tailscale を入れ、ホストが自分の端末を友達に共有する | 無料（個人のプラン） | ポート開放がいらない。ホストの 100.x の番号へつなぐだけ。家の外どうしでもつながる | 友達にアプリを 1 つ入れてもらう |
| ルーターのポート開放 | ホストのルーターで UDP 24680 を開ける | 無料 | 友達は何も入れなくてよい | ルーターの設定が要る。マンションの共用回線や携帯回線では開けられないことがある |
| 中継サーバー（VPS） | 小さなサーバーを借り、中継を置く | 月数百円〜 | 誰の家の回線にも左右されない | 借りる・立てる・止める手間 |
| Steam | Steamworks に登録し、アプリ ID を取る | 1 本 100 ドル | 友達を Steam から招ける。NAT 越えも Steam がする | 費用と審査。テストプレイには重い |

テストプレイは Tailscale から始める。友達が入れられないときだけ、ポート開放を試す。

## スタート画面

引数なしで起動すると、雪山の上に紙の札が 3 枚吊るしてある（`game/start.gd`）。文字は使わず、絵と数字だけ。

| 札 | 絵 | 押すと |
|---|---|---|
| 一人 | あなたがソリを押し、仲間（CPU）が二人ついて来る | この画面を閉じて、そのまま遊ぶ |
| ホスト | あなたの家の戸が開いていて、友達が歩いて来る。下にあなたの番号と、写すボタン（二枚重ねの紙） | 仲間を置かずに世界を作り直し、ホストになる |
| つなぐ | あなたが友達の家へ歩いて行く。下に番号を打つ欄と、行くボタン（赤いフェルトに「＞」） | 世界を作り直し、つなぎに行く。つながるまで、行くボタンの所に砂時計 |

- あなたの番号は、Tailscale の 100.x があればそれ、なければ家の中の番号（192.168.x など）。
- 前に打った番号は覚えておく（`user://net.cfg`）。「番号:ポート」でも打てる。
- つながらなかった・ホストが帰ったときは、この画面に戻り、つなぐの札の家に × を縫う。ホストになれなかったときは、ホストの札に ×。
- 遊んでいるあいだは、設定（Esc）の下に通信の様子（ホストの番号・来ている人の数）が出る。「スタート画面へ」で通信をやめて戻る。

## 起動の仕方（引数で。確かめ用）

```
# ホスト
Godot --path game -- --host
# つなぐ側（ホストの Tailscale の番号）
Godot --path game -- --join=100.x.y.z
```

- `--port=番号` で、ポートを替えられる（既定は 24680。UDP）。
- `--lag=ミリ秒` で、届いたものをわざと遅らせる（片道）。同じ Mac で遅れを確かめる用。
- 通信で遊ぶときは、仲間（CPU）を置かない。仲間はそれぞれの画面の中だけにいて、ほかの人には見えないため。`--bots=1` と書けば置ける。
- 引数を付けて起動したときは、スタート画面を出さない（`--start` で出せる）。

## 何を、誰が決めるか

| もの | 決める画面 | 送り方 |
|---|---|---|
| 自分の体（位置・向き・人形の姿勢） | その人の画面 | 1 秒に 20 回、みんなへ（届かなくてもよい送り方） |
| ソリの位置と速さ | ホスト | 1 秒に 30 回、みんなへ。止まっているソリは 1 秒に 2 回 |
| ソリを押す・紐で引く・体重移動 | その人の画面が向きを決め、ホストの画面のその人の体がホストのソリにかける | 体の姿と一緒に |
| つかむ・乗る・紐を持つ | その人の画面が決め、ほかの画面のその人の体も同じソリに同じことをする | 体の姿と一緒に |
| 引きずられて手が離れる・Backspace でソリを戻す | ホスト | ホストからその人へ（確かに届く送り方） |

| 身ぶり・声・雪玉・指さし（`emotes.gd`） | その人の画面が出し、ホストが確かめる（雪玉の数・ハイタッチ・握手・空振り・雪玉の当たりはホストだけが決める） | つなぐ側 → ホスト → 全員（確かに届く送り方）。自分の人形も、ホストから戻ってから動く |
| 雪玉の数 | ホスト | 変わったときに全員へ |
| クラフト（`craft.gd`。買う・縫う・畳む・広げる・米袋・名札・名前と色・人形・装備・ランタン） | その人の画面が出し、ホストが値段・持ち物の空きなどを確かめる | つなぐ側 → ホスト → 全員。全員が同じ順に `_apply` するので、ソリの番号もそろう |
| ミシンが縫い上げる・ボタンが財布に入る・米袋がひとりでに帯に戻る | ホストの画面 | ホスト → 全員 |
| あとから来た人 | ホスト | 来たときに、工房の持ち物・置いてあるソリ・出している米袋・雪玉の数を丸ごと渡す |

- 人の番号は、通信の番号をそのまま使う（ホストは 1）。全員の画面で同じ番号になる（`emotes.gd` の `join`）。
- 出来事のコマ（`frame`・`until`）は、送った画面の時計で書いてある。受けた画面は、送った画面の「いま」との差で自分の時計に直す。
- つなぐ側の `craft.send` は、断られたかがすぐには分からないので true を返す。結果は配られた出来事で知る。
- つなぐ側が投げた雪玉は見た目だけで、当たりはホストの雪玉が決める。
- つなぐ側のソリは、自分の画面では力で動かさない。届いた姿と速さから、いまの姿を先読みし、そこへなめらかに寄せる（`sled.gd` の `net_follow`）。
- それぞれの画面で同じ席に座ってしまったら、通信の番号の大きい人が空いた席へ移る（`remote_person.gd` の `_yield_seat`）。

## ファイル

- `game/net.gd`：ホストになる・つなぐ、姿を送る・受ける
- `game/remote_person.gd`：つないでいるほかの人の体
- `game/tools/net_shots.gd`：同じ Mac で 2 つ起動して、二人で押して乗るまでを撮る

## PR の分け方

1. つなぐ・二人が見える・一緒にソリを押して乗る（この PR）
2. スタート画面（一人・ホストになる・つなぐ）
3. 身ぶり・声・雪玉と、クラフト（お店・ミシン・名札・米袋・ランタン・人形）
4. 雪のボタン・ロッジの席・湿り気（`snow_buttons.gd`・`seats.gd`・`damp.gd`）
5. 書き出し（Mac と Windows）と、友達向けの手順書 `docs/playtest-online.md`

## まだ通信に載っていないもの

- 雪のボタン（斜面のボタンはそれぞれの画面で切れる。財布に入るのはホストが決めた分だけ）
- ロッジの席の取り合い（座る姿は届く）
- 湿り気
