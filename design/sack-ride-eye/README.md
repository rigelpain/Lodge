# 米袋に乗るときの一人称の目線（2026-11-02）

代表の声：「米袋に乗るときに視点が米袋に行ってしまって一人称プレイ時に走って乗ると爽快感が失われる。」

## 何が起きていたか

N で米袋を出して乗ると、腰を下ろすコマ（N から 0.33〜0.6 秒）で、`player.gd` の `_sack_events` がマウスで見ている上下の向き（`_pitch`）を書き換えていた。袋に対して 18° 下（`SACK_LOOK = -0.32`）まで下げ、下り坂ではその傾きも足していた。書き換えたのは見ている向きそのものなので、乗ったあともずっと下を向いたままで、マウスで上げるまで戻らなかった。走って乗っても、画面の下半分が膝と袋で埋まり、行く先が見えなかった（`fp-run-before-after.png` の上 2 段 ⑥〜⑧）。

## 直したこと

- 乗るときに、見ている向き（`_pitch`）を書き換えないようにした。走って乗れば、走っていた向きの前を見たまま滑り出す。目の高さは前と同じように、座った人形の目の所まで下がる（`ride_eye`）。速さに合わせて画角が広がる `ride_fov` もそのまま。
- 平らな所で前を見ていれば、袋の前の縁（約 18° 下）と紐を握った手（約 23° 下）が、画面の下の端に入る。立てた膝（約 32° 下）は、少し下を向くと見える。
- 三人称は、もともと書き換えていなかったので変わらない（`tp-run-before-after.png`）。

## 止まって乗るときを比べた（`fp-still-nod-compare.png`）

- 案 A：腰を下ろすコマで 7° だけひととき下げて、ひとりでに戻す（見ている向きは変えない）
- 案 B：まったく下げない

並べると A と B はほとんど見分けがつかず、下げる意味が薄いので、B（下げない）にした。

## 絵

上（左）が直す前、下（右）が直した後。撮り方は `game/tools/sack_mount_eye.gd`（`--fixed-fps 30`。`--still` で止まって乗る、`--view=tp` で三人称、`--probe` で手や袋の縁が目から何度下に見えるか）。

- `fp-run-before-after.png`・`fp-run-before-after.gif` 一人称、走りながら N（平らな所。W は押したまま）
- `fp-still-before-after.png` 一人称、止まって N
- `fp-still-nod-compare.png` 止まって乗るときの、直す前・案 A・案 B
- `tp-run-before-after.png` 三人称、走りながら N（変わらないことの確かめ）
- `fp-slope-after.png` 直した後、下り坂（20°）で止まって N。前を見たままなので、袋は画面の下に入らない
