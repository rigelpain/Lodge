# 米袋を出して乗る・しまう動き（2026-10-29）

代表の声：「米袋に乗るときに、取り出しと乗り込むモーションがないと、平べったすぎて乗っていることに気付けないです」

## 流れ（人形と同じ 12 コマ／秒）

乗る・降りるそのものは N を押した瞬間に済ませる。動きは見た目だけがコマで追いつくので、坂ならその途中から滑り出す。乗り込みの途中で Space を押して蹴ると、残りのコマを飛ばして、すぐ座った姿になる（蹴りも効く）。

| コマ | 取り出して乗る（約 0.5 秒） |
|---|---|
| 0 | 右手を帯へ（体を右の腰へひねる。ため） |
| 1 | 丸めた袋を引き抜き、胸の前で両手に |
| 2 | 両腕を前へ振り下ろす。袋が前の宙で開きかける（ばさっ） |
| 3 | 袋が雪の上に落ちて、ばさっと広がる（雪の粉）。しゃがむ。一人称は目が下がり、膝のあたりへ視線が落ちる |
| 4 | 腰を下ろす（ぽふっ）。袋のお尻の所がへこみ、まわりがふくらむ。両脇に雪の粉 |
| 5〜 | 少し後ろへもたれ、膝を立て、前の紐を両手で握る。袋は乗っているあいだ厚い |

| コマ | 立って丸めてしまう（約 0.8 秒） |
|---|---|
| 0〜1 | 立ち上がり、袋のすぐ後ろで深くかがむ |
| 2〜6 | 足もとの袋を両手で転がすように丸める（袋は折り紙のように畳まれる） |
| 7 | 跳ねた包みを両手で受ける |
| 8〜9 | 右の腰の帯へ戻す |

- 帯には、丸めて麻ひもでしばった米袋をいつも下げている（袋の色）。出しているあいだは帯から消える。
- 音：広げるときは布を振る音、座るときは布をたたく低い音と雪の音、しまうときは振る音と布の音（いまある音の素材から）。

## 乗っていると分かる見え方

- **一人称**：座ると、目が座った人形の高さまで下がる。米袋では少し後ろへもたれた所に目を置き、腰を下ろすときに視線を膝のあたりまで落とす（袋に対して 18° 下。下り坂ではその傾きも足す）。画面の下に、立てた膝と足先、紐を握った両手の袖、紐、袋の前の縁と印刷が見える。そのあとは自由に見回せる。
- **三人称・右下の小窓**：腰を落として後ろへもたれ、膝を立てて紐を握る。袋は乗っているあいだ 1.45 倍の厚みになり、座る所がへこんでまわりがふくらむ（当たり判定は変えない）。

## 作り

- `game/doll.gd`：`sack_start`・`sack_k`・`sack_seated`、取り出す（`_sack_draw`）・しまう（`_sack_stow`）のコマ、帯の丸めた袋（`_make_roll`・`_place_roll`）、米袋に座る姿勢（膝を立て、前の紐を握り、後ろへもたれる）
- `game/sack_look.gd`：袋のへこみとふくらみと厚み（頂点を動かした形を段ごとに覚える）、広げるときの袋の動き
- `game/player.gd`：N で動きを始める、出来事（広げる・座る）をコマに合わせて起こす、一人称の目・視線・手・脚
- `game/fp_hands.gd`：一人称の脚（腿・すね・足先。人形の裾と同じ柄）
- `game/audio.gd`：`sack`（広げる・座る・しまうの音）
- `game/craft.gd`：しまうときの畳む動きを 2.5 倍から 3 倍の速回しに（10 コマ。人形のしまう動きと合わせる）
