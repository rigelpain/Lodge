# 雪だるまの食べ物屋（2026-11-01 代表と決めたこと）

ロッジ 1 階、炉の右の厨房。雪だるまは冷蔵庫の中から番台ごしに **ペレット**（料理のもとの手芸の粒）を売る。**調理はプレイヤーがする**。買ったペレットを厨房の装置に入れて料理に仕上げ、持ち歩いてどこでも食べる。

## 品書きと調理の道

| 道 | 装置 | 料理 |
|---|---|---|
| 押して形に | プレス機 | おにぎり |
| 成形して揚げる | プレス機 → 乾燥機 | たい焼き・肉まん・コロッケ・ハッシュドポテト・ポテト |
| 挟んで焼く | アイロン台 | ホットサンド・焼き芋・ホットケーキ・焼きサンマ・焼き牡蠣 |
| 茹でて焼く | 乾燥機 → アイロン台 | 焼きそば |
| 回して茹でる | 乾燥機 | ラーメン・うどん・そば |
| 飲み物 | 衣類スチーマー | ココア・お汁粉・コーンポタージュ・クラムチャウダー・緑茶・ホットミルク・ミルクティー |

- 団子はやめた。ぜんざいではなくお汁粉
- 値段は雪玉（ペレット 1 つの値段）: おにぎりと飲み物は 1、ラーメンは 3、ほかは 2
- ペレットは料理ごとに色と形を変える（01_menu.png の丸の中）

## 厨房

- 並びは西から: 冷蔵庫（雪だるま）→ プレス機 → アイロン台 → 乾燥機 → 衣類スチーマー
- 冷蔵庫の扉は左（西）へ開くように逆にする。装置の並びを扉がふさがない
- 飲み物の装置は、立てて使う衣類スチーマー（布を熱で扱う道具）。水のタンクは透明なフィルムに白糸の枠で、中の水色の水と毛糸の水面が見える。ペレットを入れると泡が上がり、毛糸のホースのふくらみが上って、頭から綿の湯気がぷしゅっと出る。**ホースはタンクの口から頭まで、きちんとつなぐ**

## 調理の動き（2026-11-01 代表「アイロンがけはしないしプレス機はプレスしないし乾燥機は回らない。特に乾燥機は蓋を透明にしてほしい」）

- 動く部品は装置とは別の glb（props/build_kitchen.py の giant_iron・giant_heat_press_lid・giant_dryer_drum）にし、装置の目印 iron・hinge・drum に付けて cook_motion.gd が 12 コマ／秒で動かす
- アイロン台: アイロンが鍋敷きから持ち上がって布の上へ下り、1 往復 12 コマで台の長さの向きに 4 往復。折り返しで湯気、ペレットは押されて平たく広がる。下ろす・持ち上げるで cook_iron_in・cook_iron_done
- プレス機: 上の板はふだん 38° 開く。2 拍ごとに閉じながら柱にそって下り（蝶番が高いので、回すだけでは下の熱板に届かない）、押さえたコマで「ぼすっ」と湯気。はじめにレバーの cook_press_in、終わりに湯気が抜ける cook_press_done
- 乾燥機: 胴が 16 コマで 1 回り（人が入って回るのと同じ）。丸い戸の窓は透明なビニール（vinyl.gdshader。正面はほぼ透け、浅い角度とビニールのしわの筋だけ白い）。回っているあいだだけ胴の中に小さな灯り。奥の熱の円板は、中を白く飛ばすので外した
- 乾燥機の中身（cook_tumble.gd）: 料理ごとに汁・麺・具をフェルトの粒と毛糸で作り、胴の壁ぎわを回りながら 1 拍に 1 回はねる（落ちたコマでつぶれる）。大きな物は拍の頭に落ちて、胴の音（cook_drum_loop の「ころん」は 0.5 秒ごと）と合う
- 通信: 動きは調理のコマだけで決まるので、どの画面でも同じ形。ほかの人の調理がつなぐ側の画面で動くのは #105 が入ってから

## 食べる・ぬくもり

- 料理は持ち物に入り、持ち歩いて外でも食べられる。長押しで 3 口
- **ぬくもり**: 暖炉にあたると早く上がって、外に出ると早く冷める。食べ物は少しだけ上がって、外でも下がりにくく長く続く
- 食べたぬくもりが残っているあいだ: 外でもふるえにくい、ソリを押す力が少し増す。重ねて食べると長さが延びる
- （2026-11-01 のちに、ぬくもりもご飯の効き目も外した。ご飯は雰囲気づくりの道具。[design/damp.md](../damp.md)）

## 守ること

- ゲームの中に文字は出さない（アイコン・絵・雪玉の数で見せる）
- 形はアートコンセプトの手芸・紙の道具と材料から借りる。家電の形は混ぜない

## 買う・調理する（PR 2 で作った）

- **番台で F** → 売り場の画面（`game/food_ui.gd`）。おじいさんの売り台と同じ緑のフェルトの板とクリーム色のカード。左にペレット 22 枚（値段は綿の雪玉の数）、右に選んだ料理の絵・調理の道（装置の絵を矢印でつなぐ）・持っている雪玉・赤い丸の買うボタン（雪玉 → 手袋）。足りないと震える。閉じるのは ×・F・Esc
- 雪玉で払う（`craft.gd` の `food_buy` が `emotes.gd` の `spend` を呼ぶ）。買ったペレットは手に持つ
- **雪だるま**（`game/snowman_shop.gd`）: 待つあいだ胴が揺れ、近くの人へ頭を向ける。画面が開くとおじぎ、売れると右手のベルを振って「ちりりん」、冷蔵庫の中からペレットが番台のお皿へ跳ね、お皿から手へ飛ぶ
- **装置の前で F**（手のペレットが、その装置の番のとき）→ 調理（`game/cook_station.gd`。12 コマ／秒）
  - プレス機: 2 拍ごとに台ごと沈んで「ぼすっ」と湯気、粒が平たくなる（4 秒）
  - アイロン台: 「ジュー」、台が小刻みに揺れ、1 拍ごとに湯気（5 秒）
  - 乾燥機: 胴が回ってがたがた揺れる。揚げ物は「ぱちぱち」、麺は「ぐつぐつ」。漏斗から湯気（5 秒）
  - スチーマー: ふたが開いてぽとん → タンクの手前に泡 → ホースのふくらみが上って頭からぷしゅっ（2 回）→ 棚にカップ（6 秒）
  - できあがりはタイマーの「チン」。仕上がりが装置から手へ飛ぶ。持ち物がいっぱいなら装置の上で待つ（もう一度 F）
- **調理の曲**: 場にあるものしか鳴らない決まり（`design/sound-concept.md`）なので、装置に仕込んだオルゴールとして、装置が動いているあいだだけ装置から鳴る。120 BPM（1 拍 = 6 コマ）、4 小節 8 秒のループ。旋律は共通で、装置ごとに下の音が違う（プレス機 = フェルトのどすん、アイロン台 = シャカシャカ、乾燥機 = 木の玉のころころ、スチーマー = 泡のぽこぽこ）。台本は `sound/gen/cook.py`
- **聞いて確かめた**（earshot。最後は代表の耳で決める）: 曲 4 本はどれも「music box melody」と聞こえる（z +2.8〜+3.7）。ぐつぐつ z +4.1、ごぼごぼ z +3.8、ぽとん z +3.0、ジュー z +2.8、タイマーのチン z +2.7、ベル z +2.6、ぷしゅっ z +2.6、ぽこ（「bubble pop」z +2.8）。プレスのぼすっ は z +2.2 で弱め（キックドラムに寄る）、揚げるぱちぱち は焚き火のぱちぱちに寄る（58%）
- **乾燥機には人も入れる**: 手にペレットを持たずに F で中にとび込み、胴の中で回って紙の水が抜ける（2 秒ほどでいちばんパリッと）。中に人がいるあいだは調理できず、調理しているあいだは入れない。詳しくは `design/damp.md` の「乾燥機に入る」
- 確かめの道具: `game/tools/food_flow_shots.gd`（買う → プレス機 → 乾燥機 → スチーマー → アイロン台を通して撮る。`--devcam` で装置に寄る、`--third` で三人称）、`game/tools/food_models_shot.gd`（料理・ペレットを並べる）

## 食べる・ぬくもり（PR 3 で作った）

- **食べる**: できあがった料理を手に持って、左ボタンを押しているあいだ食べる（3 口。離すと、いまのひと口で止まる）。雪玉より先
  - 人形（`doll.gd` の身ぶり eat、16 コマ）: 料理を見下ろして右手を口の前へ運び、もぐもぐと 2 回うなずくように噛み、手を下ろす。口の所は頭の骨と腕の長さから決めるので、7 体（kasa・origami・news・robo・musha・ningyo・golem）のどれでも口の前に来る。最後のひと口のあと、ほっと息（寒い所では白く見える）
  - 一人称: 手の料理が画面の下寄りのまんなか（口もと）へ来て、噛むあいだ小さく揺れる。ひと口ごとに小さくなる
  - 音（`sound/gen/eat.py`）: やわらかい物は「もぐもぐ」、皮がぱりっとした物は「さくっ」、麺は「ずずっ」、飲み物は「ずっ・こくっ」、食べ終えて「ほっ」。**合成ではまだ食べる音に聞こえない**（earshot で z +0.3〜+0.9。もぐもぐはスネア、ずずっは風に寄る）。CC0 の録音に替えるかを代表に聞く
- **体の調子は変わらない**: ご飯は雰囲気づくりの道具（2026-11-01 代表「食べ物でのバフはやめよう。完全に雰囲気づくりの道具にしよう」）。前の「ぬくもり」（`warmth.gd`。湯たんぽの絵・ふるえを抑える・押す力 2 割増し）と、ご飯で湿り気が戻る仕組みは外した。[design/damp.md](../damp.md)
- 確かめの道具: `game/tools/eat_shots.gd`（7 体を正面から 4 コマずつ。`--fp` で一人称、`--outside` で雪の上）
